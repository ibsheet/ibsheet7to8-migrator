# getFooterRows ***(method)***

<!-- synonyms: get footer rows, footer rows, footer row objects, bottom row array, footer data rows, get bottom rows, 푸터 행, 푸터 로우 배열, 하단 행 가져오기, 푸터 데이터 행, 푸터 영역 행, getFooterRows 메소드 -->

> 푸터 영역에 있는 푸터 데이터 로우 객체들의 배열을 반환합니다. 

### Syntax
```javascript
void getFooterRows();
```

### Return Value
***array[row object]*** : 데이터 로우 객체 배열

### Example
```javascript
// 푸터 영역에 있는 푸터 데이터 로우 객체들의 배열을 반환합니다.
sheet.getFooterRows();
```
