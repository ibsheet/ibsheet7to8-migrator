# version ***(method)***

<!-- synonyms: version, ver, 버전, 버전 확인, 시트 버전, 플러그인 버전, 정보, info -->

> 인스턴스화된 시트 객체의 버전을 확인합니다.

### Syntax
```javascript
string version();
```

### Return Value
***string***: 인스턴스화된 시트 객체의 버전 및 로드된 플러그인들의 버전 문자열

### Example
```javascript
// 인스턴스화된 시트 객체의 버전 확인
sheet.version();
```
