# TabIndex ***(cfg)***

<!-- synonyms: TabIndex, tab index, tab order, TabStop order, keyboard tab order, 탭 순서, tabindex 설정, 탭 인덱스, 시트 탭 순서, TabStop 위치, 키보드 탭 이동 -->

> `TabStop` 이 설정된 경우 시트의 탭 순서의 위치를 명시하기 위해 `Tabindex`를 설정할 수 있습니다. 
>
>


### Type
`number`

### Options
|Value|Description|
|-----|-----|
|`number`|`TabIndex` 설정한 값|


### Example
```javascript
options.Cfg = {
  TabIndex: 5,         // 시트가 5번째 tabindex 를 갖도록 설정
};
```
