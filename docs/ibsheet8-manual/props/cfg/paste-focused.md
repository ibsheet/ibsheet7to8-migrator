# PasteFocused ***(cfg)***

<!-- synonyms: PasteFocused, paste focused, paste row mode, paste behavior, insert or overwrite paste, paste selection, 붙여넣기 행 동작, 붙여넣기 방식, 붙여넣기 덮어쓰기, 붙여넣기 삽입, 붙여넣기 반복 채우기, 붙여넣기 선택 영역 -->

> `Ctrl + V`로 붙여넣을 때 **데이터가 적용되는 행 기준 동작 방식**을 설정합니다.  
> 붙여넣기 시작 열은 [PasteCols](./paste-cols) 설정에 의해 결정됩니다.  
> 붙여넣기 시 반드시 해당 시트에 Focus(현재 활성 셀 또는 행)가 존재해야 합니다.

### 셀 선택 영역(Selection) 붙여넣기 동작
- 여러 셀을 선택한 경우 선택 영역 크기에 맞게 데이터가 **잘리거나 반복되어 채워집니다.**
- 이 동작은 `0`을 제외한 모든 붙여넣기 모드(`1`~`10`)에서 공통 적용됩니다.

### Type
`number`

### Options
|Value|Description|
|-----|-----|
|`0`|`붙여넣기 비활성화`<br/>붙여넣기를 수행하지 않습니다.<br/>단, 셀 편집 상태에서는 붙여넣기가 가능합니다.|
|`1`|`기존 행 덮어쓰기`<br/>포커스된 행 1개에만 붙여넣습니다.<br/>데이터가 여러 행이면 초과분은 무시됩니다.|
|`2`|`기존 행 덮어쓰기`<br/>포커스된 행부터 아래로 기존 행에 덮어씁니다.<br/>시트 끝을 초과하는 데이터는 무시됩니다.<br/>**트리**: 동일 레벨(형제행)에만 붙여넣기되며, 초과분은 무시됩니다.|
|`3`|`기존 행 덮어쓰기`<br/>`2`와 동일하게 포커스된 행부터 아래로 기존 행에 덮어씁니다.<br/>시트 끝을 초과하는 데이터는 무시됩니다.<br/>**트리**: 레벨 구분 없이 순서대로 붙여넣기되며, 초과분은 무시됩니다. (`default`)|
|`4`|`새 행 삽입 (포커스 행 아래)`<br/>포커스된 행 **아래에** 데이터 수만큼 새 행을 삽입합니다.<br/>포커스된 행 자체는 변경되지 않습니다.<br/>**트리**: 같은 레벨로 삽입됩니다.|
|`5`|`새 행 삽입 (포커스 행 위)`<br/>포커스된 행 **위에** 새 행 **1개**를 삽입합니다.<br/>데이터가 여러 행이면 초과분은 무시됩니다.<br/>포커스된 행 자체는 변경되지 않습니다.<br/>**트리**: 같은 레벨로 삽입됩니다.|
|`6`|`새 행 삽입 (포커스 행 위)`<br/>포커스된 행 **위에** 데이터 수만큼 새 행을 삽입합니다.<br/>포커스된 행 자체는 변경되지 않습니다.<br/>**트리**: 같은 레벨로 삽입됩니다.|
|`7`|`새 행 삽입 (포커스 행 위)`<br/>`5`와 동일하나, 클립보드 값이 1개이면 새 행 삽입 없이 포커스된 셀에 직접 붙여넣습니다.<br/>데이터가 여러 행이면 초과분은 무시됩니다.<br/>포커스된 행 자체는 변경되지 않습니다.<br/>**트리**: 같은 레벨로 삽입됩니다.|
|`8`|`새 행 삽입 (포커스 행 위)`<br/>`6`과 동일하나, 클립보드 값이 1개이면 새 행 삽입 없이 포커스된 셀에 직접 붙여넣습니다.<br/>포커스된 행 자체는 변경되지 않습니다.<br/>**트리**: 같은 레벨로 삽입됩니다.|
|`9`|`덮어쓰기 + 행 자동 추가`<br/>포커스된 행부터 아래로 기존 행에 덮어쓰고, 행이 부족하면 새 행을 추가합니다.<br/>**트리**: 동일 레벨(형제행)에 붙여넣기되며, 초과분은 최상위 레벨 끝에 추가됩니다.|
|`10`|`덮어쓰기 + 행 자동 추가`<br/>`9`와 동일하게 기존 행에 덮어쓰고, 행이 부족하면 새 행을 추가합니다.<br/>**트리**: 레벨 구분 없이 순서대로 붙여넣기되며, 초과분은 최상위 레벨 끝에 추가됩니다.|


### Example
```javascript
options = {
    Cfg :{
      PasteFocused: 6,  // ctrl+v 시 신규행을 추가
    }
};
```
