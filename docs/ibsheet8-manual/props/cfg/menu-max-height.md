# MenuMaxHeight ***(cfg)***

<!-- synonyms: MenuMaxHeight, menu max height, enum menu height, dropdown max height, suggest menu height, 메뉴 최대 높이, Enum 메뉴 높이, 드롭다운 최대 높이, Suggest 메뉴 높이, 메뉴 크기 제한, 콤보 메뉴 높이 -->

> `(Col, Cell)Type`이 `Enum`인 열에서 열리는 메뉴의 최대 높이를 지정합니다.
>
> `Suggest`로 열리는 메뉴에도 적용됩니다.

### Type
`string`


### Example
```javascript
options.Cfg = {
    MenuMaxHeight: 400
};
```
