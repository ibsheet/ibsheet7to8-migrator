# ClipPasteMode ***(cfg)***

> 클립보드 붙여넣기 방법을 설정합니다.


### Type
`number`


### Options

|Value|Description|
|-----|-----------|
|-1|사용 안함|
|0|선택 셀|
|1|선택 셀 기준 구분자 처리|
|2|선택 셀 기준 구분자 (부족한 경우 행추가)|
|3|신규 행|
|4|선택 영역의 크기와 무관|
