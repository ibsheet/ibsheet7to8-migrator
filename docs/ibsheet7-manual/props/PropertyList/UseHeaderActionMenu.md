# UseHeaderActionMenu ***(cfg)***

> 헤더 컨텍스트 메뉴 사용여부를 설정합니다.<br>
> 헤더메뉴를 사용함으로 설정하고 헤더메뉴를 설정하지 않는경우 자동으로 기본 메뉴가 출력됩니다.



### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|속성 사용 안함 `(Default`)|
|1|속성 사용함|
