# DownWaitImageVisible ***(cfg)***

> 파일 다운 중 대기 이미지 출력여부를 설정합니다. <br>
> 출력 안함으로 설정 시 OnDownFinish 이벤트도 발생하지 않습니다.



### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|대기이미지, 이벤트 출력 안함|
|1|대기이미지, 이벤트 출력 함 (`Default`)|
