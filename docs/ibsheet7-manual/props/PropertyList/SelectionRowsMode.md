# SelectionRowsMode ***(cfg)***

> `GetSelectionRows` 시 포커스행 포함 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|포커스행 포함함 (`Default`)|
|1|포커스행 포함하지 않음|
