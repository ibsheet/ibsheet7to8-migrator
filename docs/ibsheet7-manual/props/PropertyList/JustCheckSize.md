# JustCheckSize ***(cfg)***

> JustCheck가 `true`인 경우 셀 내에서 체크박스로 간주될 크기를 설정합니다.


### Type
`number`


### Options

|Value|Description|
|-----|-----------|
|`number`|크기값 (`Default : 20`)|
