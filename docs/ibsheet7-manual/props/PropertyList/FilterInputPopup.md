# FilterInputPopup ***(cfg)***

> 필터 셀 편집시 다이얼로그 사용 여부를 설정합니다. <br>
> 다중 필터를 사용하는 경우 입력 문자열이 길어져 입력한 검색어를 보기 어려울 수 있습니다. 이 속성을 `1` 로 설정하면 필터 입력시 팝업 다이얼로그를 이용할 수 있습니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|사용 안함 (`Default`)|
|1|사용함|
