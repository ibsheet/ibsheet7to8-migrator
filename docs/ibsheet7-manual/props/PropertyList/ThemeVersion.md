# ThemeVersion ***(cfg)***

> 사용할 테마 버전을 설정합니다.
> `주의` 이 속성 설정값과 테마의 버전이 다른 경우 화면깨짐현상이 발생할 수 있습니다.


### Type
`number`


### Options

|Value|Description|
|-----|-----------|
|1|일반 테마 버전 (`Default`)|
|2|IE10 이상 모던 테마 버전 (모던 테마 : ModernWhite, ModernBlue)|
