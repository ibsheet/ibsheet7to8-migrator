# MarkupTagDelimiter ***(cfg)***

> 서버모듈 연동시 전송되는 전문의 마크업 태그의 구분문자를 설정합니다. <br>
> 설정값은 해당 구분문자를 구분자 ","로 연결한 4개의 문자(또는 문자열)로 설정합니다.<br>
> 기본값과 다르게 설정한 경우 서버단 수행로직에서도 동일한 값 으로 각각 설정해 주어야 합니다.



### Type
`string`


### Options

|Value|Description|
|-----|-----------|
|`string`|마크업 태그의 구분문자 (`Default : <,>,</,>`)|
