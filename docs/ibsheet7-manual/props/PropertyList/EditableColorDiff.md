# EditableColorDiff ***(cfg)***

> 편집이 불가능한 셀을 색상으로 구분하여 표시할지 여부를 설정합니다.

### Type
`number`


### Options

|Value|Description|
|-----|-----------|
|0|편집불가능한 셀을 구분없이 표시합니다.|
|1|편집불가능한 셀을 css에서 설정한 색상으로 표시합니다.|
|2|편집불가능한 셀을 css의 설정값과 기본배경색의 조합으로 표시합니다.|
