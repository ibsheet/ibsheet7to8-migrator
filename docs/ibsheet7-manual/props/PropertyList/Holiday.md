# Holiday ***(cfg)***

> 달력에 표시할 사용자 정의 휴일을 설정합니다.


### Type
`string`


### Options

|Value|Description|
|-----|-----------|
|`string`|사용자가 정의할 휴일 문자열|


### Example
```html
대상 일자를 구분자 '|'로 연결한 문자열로 설정 하며 설정 값의 포맷은 'yyyyMMdd' 를 사용합니다.
매년, 매월에 대한 와일드카드로 * 을 사용합니다.

(예시)
"Holiday": "20120725|*0703|2012*27|**17"
 - *0703 : 매년 7월 3일
 - 2012*27 : 2012년 매월 27일
 - **17 : 매년, 매월 17일
```
