# SetScrollTop ***(core method)***

> 세로 스크롤의 위치를 설정 합니다.

### Syntax
```javascript
ObjId.SetScrollTop(Pos);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|Pos|`Number`|<span class="required">필수</span>|세로 스크롤 위치 (Default: 0)|


### Returns
***none***

### Example
```javascript
// 현재 세로 스크롤 위치를 30px으로 설정한다.
mySheet.SetScrollTop(30);
```
