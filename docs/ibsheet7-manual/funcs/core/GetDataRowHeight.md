# GetDataRowHeight ***(core method)***

> 데이터 행의 기본 행 높이를 확인 합니다.

### Syntax
```javascript
ObjId.GetDataRowHeight();
```

### Info
***none***



### Returns
***Number, 데이터 행 높이 (단위:px)***

### Example
```javascript
// 행의 기본 높이 확인
console.log("rowHeight:", mySheet.GetDataRowHeight());
```
