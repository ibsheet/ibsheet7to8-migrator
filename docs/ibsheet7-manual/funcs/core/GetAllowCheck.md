# GetAllowCheck ***(core method)***

> 사용자가 체크박스의 값 변경시, 값의 변경을 수용할 지의 여부를 확인합니다.

### Syntax
```javascript
ObjId.GetAllowCheck();
```

### Info
***none***



### Returns
***Boolean, 설정된 값***

### Example
```javascript
// 체크박스의 값 변경 허용여부 확인
console.log("allowCheck:", mySheet.GetAllowCheck());
```
