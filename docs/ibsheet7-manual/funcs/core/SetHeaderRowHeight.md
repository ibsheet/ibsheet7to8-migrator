# SetHeaderRowHeight ***(core method)***

> 헤더 행의 행높이를 설정합니다.

### Syntax
```javascript
ObjId.SetHeaderRowHeight(height);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|height|`Number`|<span class="required">필수</span>|설정할 높이 값 (단위:px)|



### Returns
***none***

### Example
```javascript
// 헤더행의 높이를 30픽셀로 설정 한다.
mySheet.SetHeaderRowHeight(30);
```
