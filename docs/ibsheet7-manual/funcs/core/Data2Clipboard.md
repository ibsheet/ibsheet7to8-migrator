# Data2Clipboard ***(core method)***

> IBSheet의 헤더를 포함한 모든 데이터를 클립보드에 복사 합니다.<br>
> `제약사항` 이 기능은 브라우저 보안정책상의 이유로 `IE 브라우저`만 지원합니다.

### Syntax
```javascript
ObjId.Data2Clipboard();
```

### Info
***none***



### Returns
***String, 클립보드에 복사된 문자열***

### Example
```javascript
// 모든 데이터를 클립보드에 복사
mySheet.Data2Clipboard();
```
