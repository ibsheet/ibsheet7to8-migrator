# GetTabIndex ***(core method)***

> 시트의 TabIndex 를 확인합니다.

### Syntax
```javascript
ObjId.GetTabIndex();
```

### Info
***none***



### Returns
***Number, tabIndex***

### Example
```javascript
// TabIndex 정보 확인 하기
var tabindex= mySheet.GetTabIndex();
```
