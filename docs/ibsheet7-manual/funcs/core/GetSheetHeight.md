# GetSheetHeight ***(core method)***

> 전체 높이를 확인 합니다.

### Syntax
```javascript
ObjId.GetSheetHeight();
```

### Info
***none***



### Returns
***Number, 전체 높이 (단위:px)***

### Example
```javascript
// 시트의 전체 높이 확인
console.log("sheetHeight:", mySheet.GetSheetHeight());
```
