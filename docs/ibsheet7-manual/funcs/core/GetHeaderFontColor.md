# GetHeaderFontColor ***(core method)***

> 헤더행의 폰트 색상을 확인 합니다.

### Syntax
```javascript
ObjId.GetHeaderFontColor();
```

### Info
***none***



### Returns
***String, 폰트 색상 값***

### Example
```javascript
// 헤더행의 폰트 색상 확인.
console.log("fontColor:", mySheet.GetHeaderFontColor());
```
