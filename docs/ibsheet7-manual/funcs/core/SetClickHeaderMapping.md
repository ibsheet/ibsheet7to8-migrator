# SetClickHeaderMapping ***(core method)***

> 셀 클릭시 셀에 매핑되는 헤더셀의 색상을 변경하도록 설정합니다.

### Syntax
```javascript
ObjId.SetClickHeaderMapping(mapping)
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|mapping|`Boolean`|<span class="required">필수</span>|색상 변경 여부|



### Returns
***none***

### Example
```javascript
// 셀에 매핑되는 헤더셀의 색상을 변경
mySheet.SetClickHeaderMapping(1);
```
