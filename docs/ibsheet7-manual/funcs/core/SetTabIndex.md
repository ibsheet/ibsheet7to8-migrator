# SetTabIndex ***(core method)***

> 시트에 TabIndex를 부여하여 tab을 통해 시트 안/밖으로 포커스가 움직일 수 있도록 설정합니다.

### Syntax
```javascript
ObjId.SetTabIndex(index);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|index|`Number`|<span class="required">필수</span>|설정할 TabIndex|



### Returns
***none***

### Example
```javascript
// 시트에 tabIndex를 1로 설정
mySheet.SetTabIndex (1);
```
