# GetSavingImage ***(core method)***

> 저장중 대기 이미지의 url을 확인합니다.

### Syntax
```javascript
ObjId.GetSavingImage();
```

### Info
***none***



### Returns
***String, 저장중 대기 이미지 url***

### Example
```javascript
// 저장중 대기 이미지 url 확인
console.log('saveWaitImage: ', mySheet.GetSavingImage());
```
