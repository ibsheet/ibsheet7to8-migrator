# GetDataRows ***(core method)***

> 단위데이터행 설정 개수를 확인 합니다.

### Syntax
```javascript
ObjId.GetDataRows();
```

### Info
***none***



### Returns
***Number, 설정 되어 있는 단위 데이터 행의 개수***

### Example
```javascript
// 단위데이터행의 수 확인
console.log("dataRows:", mySheet.GetDataRows());
```
