# HeaderRows ***(core method)***

> 헤더행의 개수를 확인합니다.

### Syntax
```javascript
ObjId.HeaderRows();
```

### Info
***none***



### Returns
***Number, 헤더행의 개수***

### Example
```javascript
// 헤더행의 개수 확인.
console.log("headerRows:", mySheet.HeaderRows());
```
