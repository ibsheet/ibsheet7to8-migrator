# GetWaitTimeOut ***(core method)***

> 조회, 저장 등 서버의 응답을 받는 경우 대기할 응답 대기 시간을 확인 합니다.

### Syntax
```javascript
ObjId.GetWaitTimeOut();
```

### Info
***none***



### Returns
***Number, 서버 응답 대기 시간***

### Example
```javascript
// 서버 응답 대기 시간 확인
console.log('waitTimeout: ', mySheet.GetWaitTimeOut());
```
