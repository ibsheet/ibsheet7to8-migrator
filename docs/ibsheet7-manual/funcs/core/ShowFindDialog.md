# ShowFindDialog ***(core method)***

> 찾기 다이얼로그를 표시합니다.<br>
> `ctrl + shift + F` 또는 `ctrl + alt + F` 단축키 입력시에도 찾기 다이얼로그를 표시 할 수 있습니다.

### Syntax
```javascript
ObjId.ShowFindDialog();
```

### Info
***none***



### Returns
***none***

### Example
```javascript
// 찾기 다이얼로그 표시
mySheet.ShowFindDialog();
```
