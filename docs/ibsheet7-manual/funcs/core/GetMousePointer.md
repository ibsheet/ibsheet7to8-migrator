# GetMousePointer ***(core method)***

> 시트 내에서의 마우스 커서 모양을 확인 합니다.

### Syntax
```javascript
ObjId.GetMousePointer();
```

### Info
***none***



### Returns
***String, 마우스의 모양***

### Example
```javascript
// 마우스 커서 확인
console.log("mouseCursor:", mySheet.GetMousePointer());
```
