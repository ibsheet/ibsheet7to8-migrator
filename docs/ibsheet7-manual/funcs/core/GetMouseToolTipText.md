# GetMouseToolTipText ***(core method)***

> 마우스 커서의 위치에 설정한 툴팁 문자열을 확인 합니다.

### Syntax
```javascript
ObjId.GetMouseToolTipText();
```

### Info
***none***



### Returns
***String, 설정한 툴팁 문자열***

### Example
```javascript
// 설정한 툴팁 문자열 확인
console.log("toolTip:", mySheet.GetMouseToolTipText());
```
