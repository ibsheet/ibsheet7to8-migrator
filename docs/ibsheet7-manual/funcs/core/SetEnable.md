# SetEnable ***(core method)***

> 마우스나 키보드를 사용한 User Interface 사용가능 여부를 설정 합니다.

### Syntax
```javascript
ObjId.SetEnable(enable);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|enable|`Boolean`|<span class="required">필수</span>|활성화 여부|



### Returns
***none***

### Example
```javascript
// 대상 Grid를 비활성 상태로 설정
mySheet.SetEnable(0);
```
