# GetTotalRows ***(core method)***

> 조회해야 할 전체 조회 대상 건수를 확인 합니다.

### Syntax
```javascript
ObjId.GetTotalRows();
```

### Info
***none***



### Returns
***Number, 전체 조회 대상 건수***

### Example
```javascript
// 전제 조회 대상 건수를 확인 한다.
console.log("totalRows:", mySheet.GetTotalRows());
```
