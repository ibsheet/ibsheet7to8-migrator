# GetShowSortArrow ***(core method)***

> 헤더 클릭시 Sort 정보를 나타내는 이미지 표시 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetShowSortArrow();
```

### Info
***none***



### Returns
***Boolean, 이미지 표시 여부***

### Example
```javascript
// Sort 이미지 표시 여부 확인
console.log("sortInfo:", mySheet.GetShowSortArrow());
```
