# GetDragMode ***(core method)***

> IBSheet 내에서의 drag 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetDragMode();
```

### Info
***none***



### Returns
***Number, 처리 모드***

### Example
```javascript
// DragMode 확인
console.log("dragMode:", mySheet.GetDragMode());
```
