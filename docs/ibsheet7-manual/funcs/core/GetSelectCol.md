# GetSelectCol ***(core method)***

> 현재 선택된 셀의 컬럼 Index를 확인 합니다.

### Syntax
```javascript
ObjId.GetSelectCol();
```

### Info
***none***



### Returns
***Number, 선택된 셀의 컬럼 Index***

### Example
```javascript
// 선택된 셀의 컬럼 Index 확인.
console.log("columnIndex:", mySheet.GetSelectCol());
```
