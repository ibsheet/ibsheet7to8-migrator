# GetComboOpenMode ***(core method)***

> `Combo`, `ComboEdit` 타입의 셀 선택 시점의 처리방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetComboOpenMode();
```

### Info
***none***



### Returns
***Boolean, 현재 설정 값***

### Example
```javascript
// "Combo", "ComboEdit" 타입의 셀 선택시점의 처리방법 확인
console.log("comboOpenMode:", mySheet.GetComboOpenMode());
```
