# SetSavingImage ***(core method)***

> 저장중 대기 이미지의 url을 설정 합니다.

### Syntax
```javascript
ObjId.SetSavingImage(url);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|url|`String`|<span class="required">필수</span>|저장중 대기 이미지 url|



### Returns
***none***

### Example
```javascript
// 저장중 대기 이미지 url 설정
mySheet.SetSavingImage('./img/saveProcess.png');
```
