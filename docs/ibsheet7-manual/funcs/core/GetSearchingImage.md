# GetSearchingImage ***(core method)***

> 조회중 대기 이미지의 url을 확인 합니다.

### Syntax
```javascript
ObjId.GetSearchingImage();
```

### Info
***none***



### Returns
***String, 조회중 대기 이미지 url***

### Example
```javascript
// 조회중 대기 이미지 url 확인
console.log('searchWaitImage: ', mySheet.GetSearchingImage());
```
