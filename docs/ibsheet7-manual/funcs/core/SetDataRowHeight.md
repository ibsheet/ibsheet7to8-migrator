# SetDataRowHeight ***(core method)***

> 데이터 행의 기본 행 높이를 설정 합니다.


### Syntax
```javascript
ObjId.SetDataRowHeight(height);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|height|`Number`|<span class="required">필수</span>|설정할 높이 값 (단위:px)|



### Returns
***none***

### Example
```javascript
// 행의 기본 높이를 25픽셀로 설정
mySheet.SetDataRowHeight(25);
```
