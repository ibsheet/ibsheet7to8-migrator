# GetUserAgent ***(core method)***

> 조회나 저장시 HTTP 헤더 정보에 포함되어 넘어가는 IBUserAgent의 값을 확인 합니다.

### Syntax
```javascript
ObjId.GetUserAgent();
```

### Info
***none***



### Returns
***String, 설정된 UserAgent 값***

### Example
```javascript
// IBUserAgent 설정값 확인
console.log("useAgent:", mySheet.GetUserAgent());
```
