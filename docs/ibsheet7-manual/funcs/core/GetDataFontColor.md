# GetDataFontColor ***(core method)***

> 데이터 행의 기본 폰트 색상을 확인 합니다.

### Syntax
```javascript
ObjId.GetDataFontColor();
```

### Info
***none***



### Returns
***String, 설정된 색상 값***

### Example
```javascript
// 행의 기본 폰트 색상 확인
console.log("fontColor:", mySheet.GetDataFontColor());
```
