# GetClipCutDisable ***(core method)***

> IBSheet에서 `Ctrl + X`를 이용하여 데이터를 클립보드에 잘라내기 할때의 처리 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetClipCutDisable();
```

### Info
***none***



### Returns
***Number, 클립보드 잘라내기 가능 여부 방법***

### Example
```javascript
// 클립보드 복사 처리 방법 확인
console.log('cutMode: ', mySheet.GetClipCutDisable());
```
