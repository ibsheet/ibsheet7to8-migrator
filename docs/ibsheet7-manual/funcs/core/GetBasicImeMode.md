# GetBasicImeMode ***(core method)***

> 편집 가능한 셀에 포커스 시 IME 처리 방법을 확인한다. `IE브라우저만 지원`

### Syntax
```javascript
ObjId.GetBasicImeMode();
```

### Info
***none***



### Returns
***Integer, 설정값***

### Example
```javascript
// IME 처리 방법 확인
console.log("imeMode:", mySheet.GetBasicImeMode());
```
