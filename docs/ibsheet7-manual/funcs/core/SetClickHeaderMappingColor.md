# SetClickHeaderMappingColor ***(core method)***

> 셀 클릭시 셀에 매핑되는 헤더셀의 색상을 설정합니다.

### Syntax
```javascript
ObjId.SetClickHeaderMappingColor(color);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|color|`String`|<span class="required">필수</span>|사용할 색상|



### Returns
***none***

### Example
```javascript
// 셀 클릭시 셀에 매핑되는 헤더셀의 색상을 설정
mySheet.SetClickHeaderMappingColor("#ffffff");
```
