# GetEllipsis ***(core method)***

> 모든 셀의 데이터에 대한 ellipsis 설정 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetEllipsis();
```

### Info
***none***



### Returns
***Boolean, ellipsis 설정 여부***

### Example
```javascript
// ellipsis 설정 여부 확인
console.log("ellipsisMode:", mySheet.GetEllipsis());
```
