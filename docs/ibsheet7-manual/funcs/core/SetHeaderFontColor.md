# SetHeaderFontColor ***(core method)***

> 헤더 행의 폰트 색상을 설정합니다.

### Syntax
```javascript
ObjId.SetHeaderFontColor(color);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|color|`String`|<span class="required">필수</span>|설정할 색상 값|



### Returns
***none***

### Example
```javascript
// 헤더행의 폰트 색상을 blue로 설정
mySheet.SetHeaderFontColor("blue");
mySheet.SetHeaderFontColor("#0000ff");
```
