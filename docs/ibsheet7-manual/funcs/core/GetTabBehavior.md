# GetTabBehavior ***(core method)***

> 포커스 상태에서 Tab 키 입력에 대한 동작 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetTabBehavior();
```

### Info
***none***



### Returns
***String, Tab 키 입력에 대한 동작 방법***

### Example
```javascript
// 포커스시 Tab 키 동작 방법 확인
console.log("enterBehavior:", mySheet.GetTabBehavior());
```
