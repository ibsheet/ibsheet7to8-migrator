# GetEditTabBehavior ***(core method)***

> 편집모드 상태에서 tab 키 입력에 대한 동작 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetEditTabBehavior();
```

### Info
***none***



### Returns
***String, TAB키 입력에 대한 동작 방법***

### Example
```javascript
// 편집모드시 tab 키 동작 방법 확인
console.log("tabBehavior:", mySheet.GetEditTabBehavior());
```
