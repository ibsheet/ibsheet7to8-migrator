# GetEditable ***(core method)***

> 모든 데이터영역에 대한 편집 가능 여부를 확인합니다.

### Syntax
```javascript
ObjId.GetEditable();
```

### Info
***none***



### Returns
***Boolean, 편집 가능 여부***

### Example
```javascript
// 편집 가능 여부를 확인
console.log("editable:", mySheet.GetEditable());
```
