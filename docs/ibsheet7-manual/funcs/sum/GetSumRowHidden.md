# GetSumRowHidden ***(sum method)***

> 합계행의 숨김여부를 확인합니다.

### Syntax
```javascript
ObjId.GetSumRowHidden();
```

### Info
***none***



### Returns
***Boolean, 숨김 설정 값***

### Example
```javascript
// 합계행의 숨김 여부 확인
console.log('isHidden: ', mySheet.GetSumRowHidden());
```
