# GetSumFontColor ***(sum method)***

> 합계 행의 폰트 색상을 확인 합니다. 폰트 색상 설정이 없는 경우 `""`으로 반환합니다.


### Syntax
```javascript
ObjId.GetSumFontColor();
```

### Info
***none***



### Returns
***String, 현재 합계행 글자 색상***

### Example
```javascript
// 합계 행의 폰트색상 확인
console.log("fontColor:", mySheet.GetSumFontColor());
```
