# GetAllowExpand ***(search method)***

> 트리 노드의 펼치기/닫기에 대한 허용 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetAllowExpand();
```

### Info
***none***



### Returns
***Boolean, 설정 값***

### Example
```javascript
// 펼치기/닫기에 대한 허용 여부 확인
console.log('allowExpand: ', mySheet.GetAllowExpand());
```
