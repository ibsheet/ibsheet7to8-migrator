# FindFilterRow ***(filter method)***

> 필터 행의 인덱스를 반환 합니다.

### Syntax
```javascript
ObjId.FindFilterRow();
```

### Info
***none***


### Returns
***Long, 필터행의 인덱스 (Default: -1)***

### Example
```javascript
//필터행의 행 번호를 가져온다.
var filterRow = mySheet.FindFilterRow();
```
