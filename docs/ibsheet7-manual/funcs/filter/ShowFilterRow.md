# ShowFilterRow ***(filter method)***

> 데이터 영역의 상단에 고정되는 필터 행을 생성 합니다. <br>
> `참고` 함수의 호출 시점은 초기화 이후 조회 처리전에 호출 해야 합니다.

### Syntax
```javascript
ObjId.ShowFilterRow();
```

### Info
***none***


### Returns
***none***

### Example
```javascript
//필터행 추가하기
mySheet.ShowFilterRow();
```
