# FilteredRowIndex ***(filter method)***

> 필터링 결과의 행의 인덱스를 확인 합니다.

### Syntax
```javascript
ObjId.FilteredRowIndex();
```

### Info
***none***


### Returns
***Number, 필터 행의 Index***

### Example
```javascript
// 필터링 결과 확인
console.log('filteredRows: ', mySheet.FilteredRowIndex());
```
