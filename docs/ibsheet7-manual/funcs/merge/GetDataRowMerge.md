# GetDataRowMerge ***(merge method)***

> 데이터 영역의 모든 행에 대한 가로 셀 병합 허용 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetDataRowMerge();
```

### Info
***none***


### Returns
***Boolean, 가로 셀 병합 허용 여부***

### Example
```javascript
// 데이터 영역의 모든 행에 대한 가로 셀 병합 허용 여부 확인
console.log('dataRowMerge: ', mySheet.GetDataRowMerge());
```
