# GetMergeSheet ***(merge method)***

> 시트의 셀 병합 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetMergeSheet();
```

### Info
***none***


### Returns
***Number,	셀 병합 방법***

### Example
```javascript
// 시트의 셀 병합 방법 확인
console.log('mergeMode: ', mySheet.GetMergeSheet());
```
