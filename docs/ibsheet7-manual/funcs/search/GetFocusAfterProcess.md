# GetFocusAfterProcess ***(search method)***

> 데이터 로드 후 포커스를 데이터 영역의 첫번째 셀에 설정 할지 여부를 확인합니다.

### Syntax
```javascript
ObjId.GetFocusAfterProcess();
```

### Info
***none***



### Returns
***Boolean, 설정 값***

### Example
```javascript
// 데이터 로드 후 포커스 설정 여부 확인
console.log('focus: ', mySheet.GetFocusAfterProcess());
```
