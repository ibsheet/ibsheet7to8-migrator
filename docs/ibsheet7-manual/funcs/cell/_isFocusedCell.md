# _isFocusedCell ***(cell method)***

> 대상 셀이 현재 포커스되어 있는지 여부를 반환합니다.

### Syntax
```javascript
ObjId._isFocusedCell(row, col);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|row|`object`|<span class="required">필수</span>|행 객체|
|col|`string`|<span class="required">필수</span>|컬럼명|
### Returns
***boolean, 포커스 여부***
