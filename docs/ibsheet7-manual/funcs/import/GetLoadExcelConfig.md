# GetLoadExcelConfig ***(import method)***

> LoadExcel 기본 설정 옵션을 확인 합니다.

### Syntax
```javascript
ObjId.GetLoadExcelConfig();
```

### Info
***none***


### Returns
***Object, LoadExcel Config***

### Example
```javascript
// LoadExcel Config를 확인
console.log("getLoadExcelConfig:", mySheet.GetLoadExcelConfig());
```
