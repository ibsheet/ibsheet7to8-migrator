# GetLoadTextConfig ***(import method)***

> LoadText 기본 설정 옵션을 확인 합니다.

### Syntax
```javascript
ObjId.GetLoadTextConfig();
```

### Info
***none***


### Returns
***Object, LoadText Config***

### Example
```javascript
// LoadText Config를 확인
console.log("getLoadTextConfig:", mySheet.GetLoadTextConfig());
```
