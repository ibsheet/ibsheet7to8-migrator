# GetLoadTextUrl ***(import method)***

> 텍스트 업로드 기능을 처리할 서버 페이지 경로를 확인합니다.

### Syntax
```javascript
ObjId.GetLoadTextUrl();
```

### Info
***none***


### Returns
***String, 텍스트 업로드 URL***

### Example
```javascript
// 텍스트 업로드 설정 경로를 확인
console.log("getLoadTextUrl:", mySheet.GetLoadTextUrl());
```
