# GetDown2ExcelUrl ***(export method)***

> 엑셀 다운로드 기능을 처리할 서버 페이지 경로를 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2ExcelUrl();
```

### Info
***none***


### Returns
***String, 엑셀 다운로드 URL***

### Example
```javascript
// 엑셀 다운로드 설정 경로를 확인
console.log("getDown2ExcelUrl:", mySheet.GetDown2ExcelUrl());
```
