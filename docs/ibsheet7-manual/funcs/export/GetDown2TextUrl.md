# GetDown2TextUrl ***(export method)***

> 텍스트 다운로드 기능을 처리할 서버 페이지 경로를 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2TextUrl();
```

### Info
***none***


### Returns
***String, 텍스트 다운로드 URL***

### Example
```javascript
// 텍스트 다운로드 설정 경로를 확인
console.log("getDown2TextUrl:", mySheet.GetDown2TextUrl());
```
