# GetDown2TextConfig ***(export method)***

> `Down2Text` 기본 설정 옵션을 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2TextConfig();
```

### Info
***none***


### Returns
***Object, Down2Text Config***

### Example
```javascript
// Down2Text Config를 확인
console.log("getDown2TextConfig:", mySheet.GetDown2TextConfig());
```
