# GetDown2PdfUrl ***(export method)***

> PDF 다운로드 기능을 처리할 서버 페이지 경로를 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2PdfUrl();
```

### Info
***none***


### Returns
***String, PDF 다운로드 URL***

### Example
```javascript
// PDF 다운로드 설정 경로를 확인
console.log("getDown2PdfUrl:", mySheet.GetDown2PdfUrl());
```
