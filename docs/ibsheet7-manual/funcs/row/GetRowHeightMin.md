# GetRowHeightMin ***(row method)***

> 모든 행의 최소 높이를 확인 합니다.

### Syntax
```javascript
ObjId.GetRowHeightMin();
```

### Info
***none***



### Returns
***Integer, 행의 최소 높이***

### Example
```javascript
// 행의 최소 높이를 확인
console.log("rowHeithtMin:", mySheet.GetRowHeightMin());
```
