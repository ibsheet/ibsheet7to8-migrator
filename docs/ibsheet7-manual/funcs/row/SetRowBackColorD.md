# SetRowBackColorD ***(row method)***

> 각행의 트렌젝션 상태가 삭제인 행의 배경색을 설정합니다.

### Syntax
```javascript
ObjId.SetRowBackColorD(BackColor)
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|BackColor|`String`|<span class="optional">선택</span>|WebColor 값|



### Returns
***none***

### Example
```javascript
// 트렌젝션상태가 삭제인 행의 배경색을 회색으로 설정
mySheet.SetRowBackColorD("#C0C0C0");
```
