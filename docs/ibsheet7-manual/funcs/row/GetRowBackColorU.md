# GetRowBackColorU ***(row method)***

> 각행의 트렌젝션 상태가 수정인 행의 배경색을 확인 합니다.

### Syntax
```javascript
ObjId.GetRowBackColorU();
```

### Info
***none***



### Returns
***String, 설정색상***

### Example
```javascript
// 트렌젝션상태가 수정인 행의 배경색을 확인
console.log("rowBackColorU:", mySheet.GetRowBackColorU());
```
