# GetExtendLastCol ***(col method)***

> 마지막 컬럼의 너비를 전체 너비에 맞게 자동으로 맞출것인지 여부를 확인합니다.


### Syntax
```javascript
ObjId.GetExtendLastCol();
```

### Info
***none***


### Returns
***Boolean, 확장 설정 여부 값***

### Example
```javascript
// ExtendLastCol 적용 값 확인
console.log("extendLastCol:", mySheet.GetExtendLastCol());
```
