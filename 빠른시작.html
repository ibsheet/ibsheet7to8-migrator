압축 파일로 전달받은 경우 → 원하는 위치에 풀기압축 파일 안의 폴더명

폴더를 원하는 위치에 두고, 그 폴더에서 AI 도구를 실행합니다. 진입점 파일(CLAUDE.md/GEMINI.md/.github/copilot-instructions.md)이 자동 인식되어 AGENTS.md 규칙이 적용됩니다.

설치 확인 — 필요한 것이 다 있는지 한 번에 점검합니다.

python migrate.py doctor
(선택) 프로젝트별 접두사 규칙이 있으면 migrate.config.example.json → 대상 프로젝트 루트에 migrate.config.json으로 복사·수정.
폴더 안에서 helpers/ibsheet-migration.js 만 고객 웹앱에 배포되는 산출물입니다(5번 참고). migrate.py·docs·engine·verify·samples는 변환 작업용이라 배포하지 않습니다.

변환 실행 (자연어로 요청)

src/main/webapp/.../orderList.jsp 를 IBSheet8로 변환해줘
어디에 입력? 1번에서 설치한 AI 도구의 대화창에 입력합니다 — Claude Code: 터미널 claude 실행 후 프롬프트 / Gemini: gemini / Copilot: VS Code Copilot Chat 패널.
AI가 없으면 입력할 곳이 없습니다. 이 경우 스크립트 단독으로 대신합니다 — 단, CLI와 AI는 역할이 다릅니다:
 CLI 단독 (AI 없음)AI 자연어 요청
안전한 자동 변환✅✅
판단 변환(Hidden→Visible 반전, 반환값 의미변경 등)❌ needs_review에 목록만✅ docs/ 근거로 처리
완성도80% (나머지는 사람이 손수정)완성까지
→ AI 없이 하려면 CLI 한 줄로 변환+검증까지 돌립니다. 
python migrate.py convert src/orderList.jsp --out build/
종료코드 2 가 나오면 실패가 아니라 "판단 변환이 남았다"는 신호입니다. 옆에 생긴 *.report.json의 needs_review 목록을 docs/ 보고 사람이 직접 마무리한 뒤 python migrate.py verify build/orderList.jsp --asis src/orderList.jsp로 확인합니다.
자동 변환→ 판단 변환 (docs 근거)→ 자기 검증→ 리포트
  • 한 번에 한 파일씩 변환합니다(함수 누락 방지). 폴더를 주면 순차 처리.
  • 결과는 원본 옆 *.tobe.jsp로 생성 — 원본 보존.

완료 판정 — 검증 3종 모두 PASS

검증통과 기준
residue_scanIBSheet7 잔존 = 0
jscheckJS 구문 OK
fn_parity원본 함수 누락 = 0

직접 확인할 때:

python migrate.py verify build/orderList.jsp --asis src/orderList.jsp
종료코드뜻
0완료
1검증 실패 (JS 구문 오류 또는 원본 함수 누락)
2판단 변환 필요 — 실패가 아니라 아직 남은 작업이 있다는 신호
3사용법 오류
⚠ 의미가 크게 바뀐 변환(예: GetSearchData→ajax)은 브라우저 동작 확인 필요.
⚠ 검증 3종은 정적 검사입니다. 아래 5번의 브릿지 헬퍼 배포가 빠져도 3종은 PASS로 나오지만 브라우저에서는 오류가 납니다.
5

변환 후

★ 필수 — 브릿지 헬퍼 배포 (빠뜨리면 화면이 안 뜹니다)
변환 결과는 helpers/ibsheet-migration.js 의 함수(getValue2·setAttribute2·getRowByIndex7 등 2/7 접미사)를 호출합니다. 이 파일을 웹앱에 복사하고 IBSheet8 본체 다음에 불러오세요. 공통 include에 한 번만 넣으면 됩니다. 
<script src="/js/ibsheet/ibsheet.js"></script>
<script src="/js/ibsheet/plugins/ibsheet-common.js"></script>   <!-- IB_Preset 쓰면 필요 -->
<script src="/js/ibsheet/plugins/ibsheet-excel.js"></script>    <!-- 엑셀/텍스트 다운·업로드 -->
<script src="/js/ibsheet/plugins/ibsheet-dialog.js"></script>   <!-- 찾기·피벗 다이얼로그 -->
<script src="/js/ibsheet/plugins/jszip.min.js"></script>        <!-- exportData/importData -->
<script src="/js/ibsheet/ibsheet-migration.js"></script>
변환 결과에 Extend:IB_Preset.*(Status·DelCheck 등)이 있으면 plugins/ibsheet-common.js도 함께 불러와야 합니다. 본체에 없는 전역이라, 빠뜨리면 검증 3종은 PASS인데 브라우저에서 IB_Preset is not defined로 죽습니다. CLI가 변환 결과를 보고 알려줍니다.
IBSheet8은 기능이 본체 + 플러그인으로 나뉘어 있습니다. IB_Preset.*→plugins/ibsheet-common.js, down2Excel·loadExcel·down2ExcelBuffer 계열→plugins/ibsheet-excel.js, showFindDialog·showPivotDialog 계열→plugins/ibsheet-dialog.js, exportData·importData(클라이언트 방식 엑셀)→plugins/jszip.min.js. 빠뜨리면 검증 3종은 PASS인데 브라우저에서 ... is not a function으로 죽습니다. 엑셀·텍스트 다운로드/업로드는 서버 모듈 설치까지 필요합니다. migrate.py convert가 변환 결과를 보고 알려줍니다.
다이얼로그 참고 — IBSheet7 에 대응이 있는 것은 ShowFindDialog·ShowPivotDialog 두 개뿐입니다. 엑셀 다운로드/업로드 등 나머지 다이얼로그는 IBSheet8 신규 기능이라 변환 대상이 아닙니다.
