# GoToBaseSheet ***(pivot method)***

> 피벗 설정 팝업으로부터 피벗 테이블이 화면에 표시되어 있는 경우 이 기능을 사용하면 해당 피벗 테이블의 원본 시트로 이동 합니다.<br>
> 피벗 테이블 설정 팝업의 `원본시트이동` 버튼의 기능과 동일하게 동작 합니다.


### Syntax
```javascript
ObjId.GoToBaseSheet();
```

### Info
***none***


### Returns
***none***

### Example
```javascript
// 원본 데이터 시트 출력
mySheet.GoToBaseSheet();
```
