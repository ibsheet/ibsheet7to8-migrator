# LastCol ***(col method)***

> 마지막 컬럼의 index를 반환합니다.

### Syntax
```javascript
ObjId.LastCol();
```

### Info
***none***


### Returns
***Number, 마지막 컬럼의 Index***

### Example
```javascript
// 마지막 컬럼의 Index 확인
console.log("lastColIndex:", mySheet.LastCol());
```
