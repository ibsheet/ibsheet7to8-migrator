# GetLoadExcelUrl ***(import method)***

> 엑셀 업로드 기능을 처리할 서버 페이지 경로를 설정합니다.

### Syntax
```javascript
ObjId.GetLoadExcelUrl();
```

### Info
***none***


### Returns
***String, 엑셀 업로드 URL***

### Example
```javascript
// 엑셀 업로드 설정 경로를 확인
console.log("getLoadExcelUrl:", mySheet.GetLoadExcelUrl());
```
