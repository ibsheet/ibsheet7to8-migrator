# HideFilterRow ***(filter method)***

> IBSheet 상단 고정행의 필터 행을 삭제 합니다. <br>
> 필터 행이 있는 경우 삭제되고, 없으면 아무 일도 발생하지 않습니다.

### Syntax
```javascript
ObjId.HideFilterRow();
```

### Info
***none***


### Returns
***none***

### Example
```javascript
//필터행 삭제하기
mySheet.HideFilterRow();
```
