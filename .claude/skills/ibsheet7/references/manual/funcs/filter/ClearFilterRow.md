# ClearFilterRow ***(filter method)***

> 필터 행을 초기화합니다. 초기화시 필터링이 되어있는 경우 해당 필터링은 모두 초기화 됩니다.


### Syntax
```javascript
ObjId.ClearFilterRow();
```

### Info
***none***


### Returns
***none***

### Example
```javascript
// 필터행 초기화
mySheet.ClearFilterRow();
```
