# GetTopRow ***(row method)***

> 최상단의 행 번호를 확인 합니다.


### Syntax
```javascript
ObjId.GetTopRow();
```

### Info
***none***



### Returns
***Long, 최상단의 행 번호***

### Example
```javascript
// 최상단의 행 번호를 확인
console.log("topRow:", mySheet.GetTopRow());
```
