# GetRowBackColorI ***(row method)***

> 각행의 트렌젝션 상태가 입력인 행의 배경색을 확인 합니다.

### Syntax
```javascript
ObjId.GetRowBackColorI();
```

### Info
***none***



### Returns
***String, 설정 색상***

### Example
```javascript
// 트렌젝션상태가 신규인 행의 배경색을 확인
console.log("rowBackColorI:", mySheet.GetRowBackColorI());
```
