# GetRowHeightMax ***(row method)***

> 행의 최대 높이 값을 확인 합니다.

### Syntax
```javascript
ObjId.GetRowHeightMax();
```

### Info
***none***



### Returns
***Integer, 행의 최대 높이***

### Example
```javascript
// 설정한 최대 높이값을 확인
console.log("getRowHeightMax:", mySheet.GetRowHeightMax());
```
