# GetFocusAfterRowTransaction ***(row method)***

> 행 추가 / 삭제 / 이동 / 복사 후 포커스 처리 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetFocusAfterRowTransaction();
```

### Info
***none***



### Returns
***Boolean, 설정 값***

### Example
```javascript
// 포커스를 이동 할지 여부를 확인
console.log("getFocusAfterRowTransaction:", mySheet.GetFocusAfterRowTransaction());
```
