# GetSelectionSummaryInfoElement ***(core method)***

> 선택 요약 정보 출력 대상 Dom Element를 확인 합니다.

### Syntax
```javascript
ObjId.GetSelectionSummaryInfoElement();
```

### Info
***none***



### Returns
***Object, 선택 요약 정보 출력 대상 Dom Element***

### Example
```javascript
// 선택 요약 정보가 출력 되는 Dom Element 확인
console.log('element: ', mySheet.GetSelectionSummaryInfoElement());

```
