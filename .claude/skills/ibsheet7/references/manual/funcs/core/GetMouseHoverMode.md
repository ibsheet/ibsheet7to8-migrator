# GetMouseHoverMode ***(core method)***

> 현재 설정 되어있는 마우스 Hover 모드를 확인합니다.

### Syntax
```javascript
ObjId.GetMouseHoverMode();
```

### Info
***none***



### Returns
***Number, 설정된 모드***

### Example
```javascript
// Hover 모드 확인
console.log("hoverMode:", mySheet.GetMouseHoverMode());
```
