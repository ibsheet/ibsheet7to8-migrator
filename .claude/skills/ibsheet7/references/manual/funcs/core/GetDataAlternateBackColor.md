# GetDataAlternateBackColor ***(core method)***

> 데이터 영역의 짝수번째 행의 기본 배경색을 확인 합니다.

### Syntax
```javascript
ObjId.GetDataAlternateBackColor();
```

### Info
***none***



### Returns
***String, 설정되어 있는 색상 값***

### Example
```javascript
// Alternate 배경색 확인
console.log("alternateBackColor:", mySheet.GetDataAlternateBackColor());
```
