# GetUploadingImage ***(core method)***

> 업로드중 대기 이미지의 url을 확인 합니다.

### Syntax
```javascript
ObjId.GetUploadingImage();
```

### Info
***none***



### Returns
***String, 업로드중 대기 이미지 url***

### Example
```javascript
// 업로드중 대기 이미지 url 확인
console.log('uploadWaitImage: ', mySheet.GetUploadingImage());
```
