# GetEditEnterBehavior ***(core method)***

> 편집모드 상태에서 Enter 키 입력에 대한 동작 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetEditEnterBehavior();
```

### Info
***String, Enter키 입력에 대한 동작 방법***



### Returns
***none***

### Example
```javascript
// 편집모드시 Enter키 동작 방법 확인
console.log("enterBehavior:", mySheet.GetEditEnterBehavior());
```
