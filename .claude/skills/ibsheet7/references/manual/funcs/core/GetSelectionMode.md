# GetSelectionMode ***(core method)***

> 포커스 선택 모드를 확인합니다.

### Syntax
```javascript
ObjId.GetSelectionMode();
```

### Info
***none***



### Returns
***Number, 설정 되어 있는 선택 모드 값***

### Example
```javascript
// 선택모드 확인
console.log("selectionMode:", mySheet.GetSelectionMode());
```
