# SetKeyFieldImage ***(core method)***

> 필수 입력 항목에 대한 표시 이미지 경로를 설정 합니다.

### Syntax
```javascript
ObjId.SetKeyFieldImage(path);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|path|`String`|<span class="required">필수</span>|이미지 경로|



### Returns
***none***

### Example
```javascript
// 필수 입력 항목에 대한 표시 이미지 경로 설정
mySheet.SetKeyFieldImage("/img/keyfield.gif");
```
