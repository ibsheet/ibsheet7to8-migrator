# GetTheme ***(core method)***

> 현재 설정되어 있는 테마를 확인 합니다.

### Syntax
```javascript
ObjId.GetTheme();
```

### Info
***none***



### Returns
***String, 테마에서 사용하는 class의 prefix 값***

### Example
```javascript
// 테마 확인
console.log("theme:", mySheet.GetTheme());
```
