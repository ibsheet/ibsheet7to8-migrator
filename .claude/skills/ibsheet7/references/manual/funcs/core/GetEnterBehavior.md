# GetEnterBehavior ***(core method)***

> 포커스 상태에서 Enter 키 입력에 대한 동작 방법을 확인합니다.

### Syntax
```javascript
ObjId.GetEnterBehavior();
```

### Info
***none***



### Returns
***String, Enter키 입력에 대한 동작 방법***

### Example
```javascript
// 포커스시 Enter키 동작 방법 확인
console.log("enterBehavior:", mySheet.GetEnterBehavior());
```
