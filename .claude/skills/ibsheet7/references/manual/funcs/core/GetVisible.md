# GetVisible ***(core method)***

> 시트 표시 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetVisible();
```

### Info
***none***



### Returns
***Boolean, 시트 표시 여부***

### Example
```javascript
// 시트의 표시 여부를 확인 한다.
console.log("sheetVisible:", mySheet.GetVisible());
```
