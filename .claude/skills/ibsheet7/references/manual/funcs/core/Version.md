# Version ***(core method)***

> 현재 로드된 시트에서 `ibsheet.js` 파일의 버전을 확인합니다.

### Syntax
```javascript
ObjId.Version();
```

### Info
***none***



### Returns
***String, IBSheet7 버전***

### Example
```javascript
// 현재의 IBSheet 버전 확인
console.log("version:", mySheet.Version());
```
