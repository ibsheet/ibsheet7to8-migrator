# GetSelectRow ***(core method)***

> 현재 선택된 셀의 행 Index를 확인 합니다.

### Syntax
```javascript
ObjId.GetSelectRow();
```

### Info
***none***



### Returns
***Number, 선택된 셀의 행 Index***

### Example
```javascript
// 선택된 셀의 행 Index 확인.
console.log("rowIndex:", mySheet.GetSelectRow());
```
