# IsFocused ***(core method)***

> 시트의 Focus 상태 여부를 확인합니다.

### Syntax
```javascript
ObjId.IsFocused();
```

### Info
***none***



### Returns
***Boolean, Focus 상태***

### Example
```javascript
// 시트의 Focus 여부 확인
console.log("focused", mySheet.IsFocused());
```
