# SetBlur ***(core method)***

> IBSheet7 에 대한 `blur` 처리를 합니다.

### Syntax
```javascript
ObjId.SetBlur(clearActive);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|clearActive|`Boolean`|<span class="optional">선택</span>|레이어 팝업창 사용시 마우스 Active된 시트객체를 제거 (wheel 스크롤)|



### Returns
***none***

### Example
```javascript
// IBSheet에 대한 blur 처리
mySheet.SetBlur();
```
