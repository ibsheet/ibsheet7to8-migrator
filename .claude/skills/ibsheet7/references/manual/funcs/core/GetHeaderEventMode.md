# GetHeaderEventMode ***(core method)***

> 헤더 행에 대한 이벤트 발생 모드를 확인 합니다.

### Syntax
```javascript
ObjId.GetHeaderEventMode();
```

### Info
***none***



### Returns
***Number, 이벤트 발생 모드***

### Example
```javascript
// 헤더 행에 대한 마우스 이벤트 발생 모드 확인
console.log("eventMode:", mySheet.GetHeaderEventMode());
```
