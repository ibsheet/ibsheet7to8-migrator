# GetHeaderFontBold ***(core method)***

>  헤더 행의 폰트 bold 적용 여부를 확인 합니다.

### Syntax
```javascript
ObjId.GetHeaderFontBold();
```

### Info
***none***



### Returns
***Boolean, bold 적용 여부***

### Example
```javascript
// 헤더행의 Bold 적용 여부 확인.
console.log("fontBold:", mySheet.GetHeaderFontBold());
```
