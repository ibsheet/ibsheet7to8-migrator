# GetPagingPosition ***(core method)***

> 페이지 내비게이션이 출력 되는 위치를 확인 합니다.

### Syntax
```javascript
ObjId.GetPagingPosition();
```

### Info
***none***



### Returns
***Number, 페이지 내비게이션 출력 위치***

### Example
```javascript
// 건수 정보 출력 위치 확인
console.log('pagingPosition: ', mySheet.GetPagingPosition());
```
