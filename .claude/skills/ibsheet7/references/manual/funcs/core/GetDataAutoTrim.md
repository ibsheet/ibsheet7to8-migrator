# GetDataAutoTrim ***(core method)***

> 데이터에 대한 자동 trim 처리 여부를 확인 합니다. <br>
> 설정하지 않은 경우 기본값인 `1`을 리턴 합니다.

### Syntax
```javascript
ObjId.GetDataAutoTrim();
```

### Info
***none***



### Returns
***Boolean, trim 처리 여부***

### Example
```javascript
// 자동 trim 여부 확인
console.log("autoTrim:", mySheet.GetDataAutoTrim());
```
