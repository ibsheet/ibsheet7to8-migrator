# GetSheetWidth ***(core method)***

> 전체 너비를 확인 합니다.

### Syntax
```javascript
ObjId.GetSheetWidth();
```

### Info
***none***



### Returns
***Number, 전체 너비 (단위:px)***

### Example
```javascript
// 시트의 전체 너비 확인
console.log("sheetWidth:", mySheet.GetSheetWidth());
```
