# GetCountInfoElement ***(core method)***

> 건수 정보 출력 대상 Dom Element를 확인 합니다.

### Syntax
```javascript
ObjId.GetCountInfoElement();
```

### Info
***none***



### Returns
***Object,건수 정보 출력 대상 Dom Element***

### Example
```javascript
// 건수 정보가 출력 되는 Dom Element 확인
console.log('element: ', mySheet.GetCountInfoElement());
```
