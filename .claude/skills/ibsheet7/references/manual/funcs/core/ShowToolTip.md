# ShowToolTip ***(core method)***

> 데이터 영역의 모든 셀에 대한 툴립 사용 여부를 설정합니다.

### Syntax
```javascript
ObjId.ShowToolTip(use);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|use|`Boolean`|<span class="required">필수</span>|툴팁 사용 여부|



### Returns
***none***

### Example
```javascript
// 데이터 영역의 모든 셀에 대한 툴팁 사용 설정
mySheet.ShowToolTip(1);
```
