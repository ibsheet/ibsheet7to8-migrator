# SetScrollLeft ***(core method)***

> 가로 스크롤의 위치를 설정 합니다.

### Syntax
```javascript
ObjId.SetScrollLeft(Pos);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|Pos|`Number`|<span class="required">필수</span>|가로 스크롤 위치 (Default: 0)|


### Returns
***none***

### Example
```javascript
// 현재 가로 스크롤 위치를 30px으로 설정한다.
mySheet.SetScrollLeft(30);
```
