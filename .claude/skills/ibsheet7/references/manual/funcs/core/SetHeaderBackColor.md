# SetHeaderBackColor ***(core method)***

> 헤더행의 배경색을 설정합니다.

### Syntax
```javascript
ObjId.SetHeaderBackColor(color);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|color|`String`|<span class="required">필수</span>|설정할 색상 값|



### Returns
***none***

### Example
```javascript
// 헤더행의 배경색을 red로 설정
mySheet.SetHeaderBackColor("red");
mySheet.SetHeaderBackColor("#ff0000");
```
