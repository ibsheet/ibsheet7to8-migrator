# GetCountFormat ***(core method)***

> 건수 정보의 출력 포맷을 확인 합니다.

### Syntax
```javascript
ObjId.GetCountFormat();
```

### Info
***none***



### Returns
***Sring, 설정된 출력 포맷***

### Example
```javascript
// 건수 정보 출력 포맷 확인
console.log('format: ', mySheet.GetCountFormat());
```
