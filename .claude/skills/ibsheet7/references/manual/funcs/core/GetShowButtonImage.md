# GetShowButtonImage ***(core method)***

> `Popup`, `Combo`, `Date` 데이터 타입 등에서의 버튼 이미지에 대한 표시 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetShowButtonImage();
```

### Info
***none***



### Returns
***Number, 버튼 이미지 표시 방법***

### Example
```javascript
// 버튼 이미지 표시 방법 확인
console.log("buttonImageMode:", mySheet.GetShowButtonImage());
```
