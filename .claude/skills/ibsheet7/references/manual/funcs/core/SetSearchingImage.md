# SetSearchingImage ***(core method)***

> 조회중 대기 이미지의 url을 설정 합니다.

### Syntax
```javascript
ObjId.SetSearchingImage(url);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|url|`String`|<span class="required">필수</span>|조회중 대기 이미지 url|




### Returns
***none***

### Example
```javascript
// 조회중 대기 이미지 url 설정
mySheet.SetSearchingImage('./img/searchProcess.png');
```
