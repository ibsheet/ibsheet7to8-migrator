# ClearHeaderCheck ***(core method)***

> 헤더의 체크박스 값을 모두 클리어 합니다. <br>
> 전체체크의 기능 처리는 하지 않고 단순 언체크 처리만 합니다.

### Syntax
```javascript
ObjId.ClearHeaderCheck();
```

### Info
***none***



### Returns
***none***

### Example
```javascript
// 헤더의 전체 체크박스를 모드 클리어 처리
mySheet.ClearHeaderCheck();
```
