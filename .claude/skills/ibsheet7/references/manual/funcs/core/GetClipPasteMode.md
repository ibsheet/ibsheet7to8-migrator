# GetClipPasteMode ***(core method)***

> 클립보드에 있는 내용을 시트에 붙여넣기 할때의 처리 방법을 확인 합니다.

### Syntax
```javascript
ObjId.GetClipPasteMode();
```

### Info
***none***



### Returns
***Number, 붙여넣기 처리 방법***

### Example
```javascript
// 클립보드 붙여넣기 처리 방법 확인
console.log('pasteMode: ', mySheet.GetClipPasteMode());
```
