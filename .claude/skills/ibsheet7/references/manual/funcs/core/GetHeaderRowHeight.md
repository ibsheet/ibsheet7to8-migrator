# GetHeaderRowHeight ***(core method)***

> 헤더행의 높이를 확인합니다.

### Syntax
```javascript
ObjId.GetHeaderRowHeight();
```

### Info
***none***



### Returns
***Number, 높이 값 (단위:px)***

### Example
```javascript
// 헤더행의 높이 확인.
console.log("rowHeight:", mySheet.GetHeaderRowHeight());
```
