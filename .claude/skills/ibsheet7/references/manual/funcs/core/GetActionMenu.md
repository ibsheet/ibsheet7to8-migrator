# GetActionMenu ***(core method)***

> 데이터 영역에 설정 되어있는 컨텍스트 메뉴를 확인 합니다.

### Syntax
```javascript
ObjId.GetActionMenu();
```

### Info
***none***



### Returns
***String(Object), 설정된 팝업메뉴***

### Example
```javascript
// 데이터 영역에 설정 되어있는 컨텍스트 메뉴 확인
console.log('contextMenu: ', mySheet.GetActionMenu());
```
