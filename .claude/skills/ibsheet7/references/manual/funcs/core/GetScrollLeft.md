# GetScrollLeft ***(core method)***

> 가로 스크롤의 현재 위치를 확인 합니다.

### Syntax
```javascript
ObjId.GetScrollLeft();
```

### Info
***none***


### Returns
***Integer, 현재 설정값***

### Example
```javascript
//현재 가로 스크롤의 위치를 확인한다.
console.log("HScrollLeftPos : ", mySheet.GetScrollLeft());
```
