# SetDataFontColor ***(core method)***

> 데이터 행의 기본 폰트 색상을 설정합니다.

### Syntax
```javascript
ObjId.SetDataFontColor(color);
```

### Info
|Parameter|Type|Required|Description|
|---------|----|--------|-----------|
|color|`String`|<span class="required">필수</span>|설정할 색상 값|



### Returns
***none***

### Example
```javascript
// 행의 기본 폰트 색상을 blue로 설정
mySheet.SetDataFontColor("blue");
mySheet.SetDataFontColor("#0000ff");
```
