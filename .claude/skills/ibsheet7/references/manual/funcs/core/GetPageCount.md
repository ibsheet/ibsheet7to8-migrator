# GetPageCount ***(core method)***

> `SearchMode`에서 사용되는 Page 개수를 확인 합니다.

### Syntax
```javascript
ObjId.GetPageCount();
```

### Info
***none***



### Returns
***Number, Page 개수***

### Example
```javascript
// Page 개수 확인
console.log("page:", mySheet.GetPageCount());
```
