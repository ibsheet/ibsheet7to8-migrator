# GetFocusEditMode ***(core method)***

> 편집 가능한 셀이 선택상태가 되었을때 바로 편집모드로 변경할지 여부를 확인합니다.

### Syntax
```javascript
ObjId.GetFocusEditMode();
```

### Info
***none***



### Returns
***Number, 편집모드 변경 여부***

### Example
```javascript
// 포커스시 편집모드 변경 여부 모드 확인
console.log("focusEditMode:", mySheet.GetFocusEditMode());
```
