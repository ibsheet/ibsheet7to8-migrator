# GetHeaderCursor ***(core method)***

> 헤더 행의 마우스 오버시 커서 모양을 확인합니다.

### Syntax
```javascript
ObjId.GetHeaderCursor();
```

### Info
***none***



### Returns
***String***

### Example
```javascript
// 헤더의 마우스 커서포인터를 확인한다.
mySheet.GetHeaderCursor();
```
