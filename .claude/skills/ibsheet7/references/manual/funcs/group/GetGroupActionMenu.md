# GetGroupActionMenu ***(group method)***

> 그룹행 영역에 설정된 컨텍스트 메뉴를 확인 합니다.


### Syntax
```javascript
ObjId.GetGroupActionMenu();
```

### Info
***none***

### Returns
***Object, MenuText, MenuCode로 이루어진 객체***

### Example
```javascript
// 그룹행의 컨텍스트 메뉴 확인
console.log("groupMenu:", mySheet.GetGroupActionMenu());
```
