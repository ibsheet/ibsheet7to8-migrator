# GetSumBackColor ***(sum method)***

> 합계 행의 배경색을 확인 합니다.

### Syntax
```javascript
ObjId.GetSumBackColor();
```

### Info
***none***



### Returns
***String, WebColor 값***

### Example
```javascript
// 합계 행의 배경색 확인
console.log("sumBackColor:", mySheet.GetSumBackColor());
```
