# FindFooterRow ***(sum method)***

> FooterRow의 인덱스를 반환합니다.

### Syntax
```javascript
ObjId.FindFooterRow();
```

### Info
***none***

### Returns
***Integer, 푸터행의 인덱스를 구분자 `|`로 연결한 문자열 (Default: -1)***

### Example
```javascript
// 합계 행의 Index 확인
console.log('FooterRows: ', mySheet.FindFooterRow());
```
