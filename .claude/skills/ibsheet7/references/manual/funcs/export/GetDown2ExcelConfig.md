# GetDown2ExcelConfig ***(export method)***

> Down2Excel 기본 설정 옵션을 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2ExcelConfig();
```

### Info
***none***


### Returns
***Object, Down2Excel Config***

### Example
```javascript
// Down2Excel Config를 확인
console.log("getDown2ExcelConfig:", mySheet.GetDown2ExcelConfig());
```
