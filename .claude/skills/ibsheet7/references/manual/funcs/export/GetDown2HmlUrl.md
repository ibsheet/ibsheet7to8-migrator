# !GetDown2HmlUrl ***(export method)***

> Hml 다운로드 기능을 처리할 서버 페이지 경로를 확인 합니다.

### Syntax
```javascript
ObjId.GetDown2HmlUrl();
```

### Info
***none***


### Returns
***String, Hml 다운로드 URL***

### Example
```javascript
// Hml 다운로드 설정 경로를 확인
console.log("getDown2HmlUrl:", mySheet.GetDown2HmlUrl());
```
