# UseJsonTreeLevel ***(cfg)***

> Json 형식의 데이터 구조에서 트리 형식 구성시 `Level`속성을 이용하여 구성할지 여부를 설정합니다.



### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|Level 속성 사용 안함 (`Default`)|
|1|Level 속성을 사용함|
