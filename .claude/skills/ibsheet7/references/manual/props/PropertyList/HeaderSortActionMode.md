# HeaderSortActionMode ***(cfg)***

> 단일 컬럼 정렬, 다중 컬럼 정렬을 위한 헤더의 사용자 입력 방식 모드를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|입력방식 : Click,	다중 컬럼 정렬 (`Default`)|
|0|입력방식 : Ctrl + Click, 단일 컬럼 정렬|
|1|입력방식 : Click,	단일 컬럼 정렬|
|1|입력방식 : Ctrl + Click, 다중 컬럼 정렬|
