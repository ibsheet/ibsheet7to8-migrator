# DirectDownMode ***(cfg)***

> `ExportMode 2 또는 3` 에서 DirectDown2Excel을 서버 모듈로 사용할 지 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|사용 안함 (`Default`)|
|1|사용 함|
