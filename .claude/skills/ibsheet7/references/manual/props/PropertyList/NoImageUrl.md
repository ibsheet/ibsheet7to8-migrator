# NoImageUrl ***(cfg)***

> 이미지 경로가 잘못된 경우 대체할 이미지의 경로를 설정합니다.<br>
> 설정시 기본경로는 `ibsheet.js` 파일위치를 기준으로 합니다. <br>
> `주의` 해당 속성의 이미지 경로가 잘못된 경우, 성능 문제가 발생할 수 있기 때문에 정확하게 설정해 주어야 합니다.


### Type
`string`


### Options

|Value|Description|
|-----|-----------|
|`string`|대체할 이미지 경로|
