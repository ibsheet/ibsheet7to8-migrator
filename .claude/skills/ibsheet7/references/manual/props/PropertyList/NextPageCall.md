# NextPageCall ***(cfg)***

> 조회 모드가 `서버페이징`, `LazyLoad` 방식인 경우 다음 페이지를 호출하는 시점을 설정합니다.
> %에 해당하는 숫자값으로 `60 ~ 90` 의 값만 설정이 가능합니다.



### Type
`number`


### Options

|Value|Description|
|-----|-----------|
|`number`|다음 페이지 호출하는 시점 (`60 ~ 90`)|
