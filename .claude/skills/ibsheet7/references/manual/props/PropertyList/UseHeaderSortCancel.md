# UseHeaderSortCancel ***(cfg)***

> 헤더 클릭을 통한 컬럼 Sort 처리시 취소 모드 사용 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|속성 사용 안함 (`Default`)<br>헤더 클릭시 Asc / Desc 순으로 처리|
|1|속성 사용함<br>헤더 클릭시 Asc / Desc / 취소 순으로 처리|
