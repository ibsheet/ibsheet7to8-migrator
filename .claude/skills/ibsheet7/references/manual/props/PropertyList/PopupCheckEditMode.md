# PopupCheckEditMode ***(cfg)***

> 컬럼 팝업메뉴를 통한 값 설정시 편집 가능여부에 따른 처리 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|편집가능여부와 무관하게 처리|
|1|편집가능한 경우에만 처리 (`Default`)|
