# FitSizeColHeaderMode ***(cfg)***

> 컬럼에 대한 FitSize 처리시 컬럼간 셀병합이 되어있는 헤더를 포함하여 처리할지 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|포함하여 처리 (`Default`)|
|1|제외하고 처리|
