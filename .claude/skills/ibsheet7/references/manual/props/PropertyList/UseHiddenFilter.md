# UseHiddenFilter ***(cfg)***

> 필터 행 없이 필터링 사용 여부를 설정합니다.


### Type
`boolean`


### Options

|Value|Description|
|-----|-----------|
|0|속성 사용 안함 (`Default`)|
|1|속성 사용함<br>필터행이 보이지 않아도 `SetFilterValue`를 사용 할 수 있게 설정|
