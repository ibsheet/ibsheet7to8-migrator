# CalButtons ***(cfg)***

> 달력팝업의 사용할 버튼을 설정합니다.<br>
> 사용하고자 하는 버튼을 `"|"` 로 연결하여 설정합니다.
> 이 속성은 시트내의 달력팝업에만 적용됩니다.


### Type
`string`


### Options

|Value|Description|
|-----|-----------|
|Close|취소 버튼|
|Today|오늘일자 입력 버튼|
|Yesterday|어제일자 입력 버튼|
|InputEmpty|빈값 입력 버튼|
|Ok|선택 버튼|
