# TrueValue ***(cfg)***

> 1 이외의 CheckBox형태 컬럼의 True 값을 지정합니다.<br>
> <span style="color:blue;">Ex)</span> "M" 으로 지정한 경우 1 대신 "M"을 True 값으로 사용 가능합니다.


### Type
`string`


### Options

|Value|Description|
|-----|-----------|
|`string`|CheckBox에서 true(1) 값 대신 사용할 문자|
