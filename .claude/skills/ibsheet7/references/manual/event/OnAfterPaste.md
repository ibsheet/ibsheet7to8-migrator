# OnAfterPaste ***(event)***

> 클립보드 붙여넣기 완료 시점에 이벤트가 발생합니다.


### Syntax
```javascript
function 오브젝트ID_OnAfterPaste() { }
```

### Parameters
***none***



### Example
```javascript
function mySheet_OnAfterPaste() {
    console.log("클립보드 붙여넣기 완료");
}
```
