# ibsheet7 페이지 로딩 속도 관련 기능 정리

아이비시트 페이지 로딩 속도 관련 기능 정리

로딩속도에 영향을 미치는 부분들

cfg,css 파일등에 대한 cache 제어IBSheet는 기본적으로 css 파일이나 license 파일 등을 caching 하지 못하도록 파일 호출시 임의의 값을 붙임.매번 해당 파일을 서버로부터 가져옴으로, 트레픽 증가함. 이를 캐싱하기 위해서는 ibsheet.cfg 폴더에 UseCache = "1" 로 설정하면 최초 파일을 가져온 이후로는 캐싱된 파일을 사용하게 된다.

디자인 관련 함수 사용 금지SetHeadBackColor(),SheetFontColor(),SheetBackColor() 과 같은 함수는 시트가 그려지고 난 후 다시 css 의 재조정을 일으키므로, 가급적 함수대신 ibsheet.css 파일을 수정해서 사용할 것.

SetMergeSheet() 메서드 사용 금지꼭 필요한 경우에만 사용하고, 여러개 머지해야 하는 건이 있는 경우에는 배열로 만들어 한번만 호출하게 끔 할 것.

테마 변경 주의SetTheme()함수를 통해 시트의 테마를 바꾸는 경우에 시트는 처음 로딩시 가져온 Main테마를 제거하고 다시 가져온 테마의 css 를 반영하게 됨으로 많은 시간이 소요되게 된다.따라서 프로젝트 안에서 모든 화면의 시트 테마가 동일하다면 SetTheme함수를 써서 테마를 바꾸는 것 보다, Main테마 폴더의 이미지나 css를 원하는 디자인의 테마로 바꾸는 것이 좋다.단 한 프로젝트에서 테마가 여러종류를 사용할 수 있다면 ibsheet.cfg 파일에서 SkipDefaultTheme값을 1로 설정하고, SetTheme() 메서드를 호출하는 것이 효율적이다. 이를 사용하는 경우에는 SetTheme로 강제로 테마를 적용하지 않으면 기본테마가 적용되지 않는다.
