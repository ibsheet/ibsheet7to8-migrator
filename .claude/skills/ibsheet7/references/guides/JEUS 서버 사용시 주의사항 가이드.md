# JEUS 서버 사용시 주의사항 가이드

JEUS 서버 사용시 주의사항 가이드

2015.04.23

기술지원팀

일반전인 WAS와 달리 jeus 서버를 사용하는 경우에는 몇 가지 주의해야 할 부분이 있다.

1. 파일 확장자 처리일반적인 WAS와 달리 jeus는 mine 타입으로 지정되지 않는 확장자를 갖는 파일을 내보내지 않는다. 따라서 ibsheet에서 사용하는 ibmsg (확장자 없음)나 ibsheet.cfg (일반적이지 않은 확장자) 파일을 사용하려면 jeus의 mine 타입에 대해 설정하여야 한다.

하지만 mine 타입을 설정하기 까다로운 경우에는 다음과 같은 방법으로 이를 해결할 수 있다.

1) ibsheetinfo.js 파일을 열어 createIBSheet 나 createIBSheet2 함수에 아래와 같은 구문을 넣는다.

Grids.Locale = locale;Grids.BaseFileExt = "xml"; //이 부분 추가

2) ibmsg 파일을 ibmsg.xml , ibsheet.cfg 파일을 ibsheet.cfg.xml 파일로 확장자를 변경한다.

(개발자 가이드 4.2 장에 참고2. )단 이 속성은 license 파일에는 적용되지 않으며, license 파일에 특정 확장자를 적용하고자 하는 경우에는 ibsheet.cfg 파일에 LicenseFileName 속성을 설정하여야 한다.ex) LicenseFileName = "license.txt"

2. 엑셀 다운로드시 서버에 쿠키 허용 문제

Down2Excel()과 같은 함수를 호출 시 시트의 데이터를 모아 서버로 전달하고 서버에서 엑셀파일을 생성하여 다시 클라이언트측으로 내려지는 형태로 엑셀 파일에 대한 export 가 이루어진다.

이때 클라이언트에서 데이터를 전송 후 엑셀 파일이 돌아오기까지 시트 위에 대기 이미지를 표시하게 되는데, 시트는 데이터를 전송한 시점부터 주기적으로 쿠키 값의 변화를 감시하고, 서버 모듈은 파일을 전송한 후 쿠키 값을 바꾸는 것으로 파일 전송이 완료되었음을 클라이언트에게 알리게 된다.

그런데 jeus 서버는 쿠키에 대한 사용이 기본적으로 막혀 있어 클라이언트에서는 파일이 모두 전송되었는지를 알 방법이 없다. 따라서 서버 엔지니어를 통해 쿠키 사용이 가능하게끔 서버 설정을 변경해야 한다.

만약 보안상의 이유로 쿠키를 사용하면 안되는 환경이라면 ibsheet.cfg에서 DownWaitImageVisible 속성으로 0으로 설정해야 한다.

단 이 경우 Down2Excel()함수 호출 시 시트 위에 대기 이미지가 표시되지 않으며, 파일을 리턴 받은 뒤 발생하는 OnDownFinish 이벤트도 발생하지 않게 된다.
