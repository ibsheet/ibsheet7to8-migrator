## 시트 생성 함수·오류

### [INIT-0001] IBSheet7의 create 메소드는 동기 방식인가요, 비동기 방식인가요? IBSheet8과 차이는?

**질문**

- IBSheet7의 create 메소드는 동기 방식인가요, 비동기 방식인가요? IBSheet8과 동작이 다른가요?

**답변**

`create` 메소드는 IBSheet7에서는 동기 방식으로, IBSheet8에서는 비동기 방식으로 동작합니다.

**키워드**: create, 동기, 비동기, IBSheet8

### [INIT-0002] createIBSheet2의 인자(obj, sheetid)에는 무엇을 넣고, 시트를 생성하는 DIV에 style을 지정해도 되나요?

**질문**

- createIBSheet2를 사용할 때 obj 인자에는 무엇을 넣어야 하나요? div id를 넣는 건가요?
- jQuery dialog 안에서 시트를 생성하려는데 시트가 나타나지 않고 오류가 납니다. 시트 생성 함수 호출을 어떻게 해야 하나요?
- 하위 시트를 동적으로 생성하려고 시트 이름을 변수로 받아 createIBSheet2를 호출했더니 오류가 납니다.
- createIBSheet2로 시트를 만들 때 시트를 생성하는 DIV 객체에 별도의 style을 지정해도 되나요?

**답변**

`createIBSheet2`를 호출할 때 다음을 지킵니다.

- 첫 번째 인자(obj)는 object로 전달해야 합니다. `document.getElementById(div id)`로 얻은 DOM 객체를 넣으며, id 문자열을 넘기면 오류가 발생해 시트가 생성되지 않습니다.
- 두 번째 인자는 string 형태로 주어야 합니다. 시트를 동적으로 생성할 때 이 인자를 문자열로 전달하는지 확인하세요.
- 시트를 생성하는 DIV 객체에는 별도의 style을 설정하면 안 됩니다. IBSheet가 자신의 크기를 계산할 때 해당 DIV를 참조하므로 오차가 생길 소지가 있습니다.
- 아주 오래된 버전의 ibsheetinfo.js에는 `createIBSheet2`가 들어 있지 않을 수 있습니다.
- 개발자 가이드(도움말)의 '4.2 IBSheet객체를 화면에 추가' 항목에서 `createIBSheet2` 관련 목차를 확인할 수 있습니다.

**키워드**: createIBSheet2, document.getElementById, obj, ibsheetinfo.js, 시트 생성 DIV, sheetid

### [INIT-0003] createIBSheet2에서 `IBSheet container is null` 또는 clientWidth null 오류가 나는 원인

**질문**

- 라이선스만 교체했는데 콘솔에 [createIBSheet2] IBSheet container is null 오류가 출력됩니다. 원인이 무엇인가요?
- 모달 화면에서 시트를 createIBSheet2로 초기화할 때 TypeError: Cannot read properties of null (reading 'clientWidth') 오류가 납니다.
- 특정 화면 로드 시 오류 메시지가 발생하며 개발서버는 정상이고 운영서버에서만 나타납니다.
- createIBSheet() 함수에서 오류가 나는데 시트를 넣을 영역이 만들어지지 않는 등 페이지 구성에서 확인할 점이 있나요?

**답변**

시트를 붙일 컨테이너(div)가 없거나 null이면 오류가 발생합니다. 다음을 확인합니다.

- `createIBSheet2`에 전달하는 div가 실제로 존재하는지 확인합니다. 컨테이너로 사용할 div를 가져오는 코드(예: jQuery 선택자)가 주석 처리되어 있는 경우 `[createIBSheet2] IBSheet container is null` 오류가 납니다.
- 개발 환경은 정상이고 운영 환경에서만 오류가 나면 소스 보기로 받은 코드를 비교해 운영 쪽 코드에 div가 누락되지 않았는지 확인합니다.
- velocity를 잘못 사용해서 시트 영역이 만들어지지 않으면 `createIBSheet()`에서 오류가 발생합니다. 시트를 넣을 영역이 페이지에 실제로 생성되었는지 확인합니다.
- 시트 크기를 계산하는 사용자 정의 함수가 `DIV_`+시트 id로 컨테이너를 찾는 경우, `createIBSheet2`로 생성한 시트에서는 `DIV_`를 찾을 수 없어 null이 되고 그 `clientWidth`를 읽다가 `Cannot read properties of null (reading 'clientWidth')` 오류가 납니다. `createIBSheet`로 만든 시트에는 `DIV_`+sheetid 컨테이너가 있으므로 두 생성 함수를 함께 쓰는 환경에서는 컨테이너 id 차이를 처리해야 합니다.

**키워드**: createIBSheet2, IBSheet container is null, clientWidth, DIV_, createIBSheet, velocity

### [INIT-0004] CK에디터와 같이 쓰거나 버튼 클릭으로 div를 동적으로 만들어 시트를 붙일 때 createIBSheet2를 써야 하는 이유

**질문**

- 같은 페이지에서 시트와 CK에디터를 함께 쓰면 에디터가 보이지 않고, div 안에 시트를 동적으로 생성하면 시트 생성이 멈춥니다. 어떻게 해결하나요?
- 버튼을 누를 때 div를 만들고 그 안에 시트를 붙이는 형태로 구현하는데 제대로 동작하지 않습니다. 어떤 함수를 써야 하나요?

**답변**

`createIBSheet`로 시트를 그리면 안 되고 `createIBSheet2`로 그려야 합니다. 같은 페이지에서 CK에디터와 함께 쓸 때, 동적으로 시트를 생성할 때 생성이 멈추는 경우, 버튼을 누를 때 div를 만들고 거기에 시트를 붙이는 형태에서 모두 `createIBSheet2`를 사용합니다.

**키워드**: createIBSheet2, createIBSheet, 동적 생성, CK에디터, div

### [INIT-0005] createIBSheet로 만든 시트 객체를 사용할 때 sheetid가 문자열이라 메서드 호출이 안 되거나 객체가 사라지는 경우

**질문**

- createIBSheet로 시트를 만들면 sheetid 문자열만 전달받는데, SetDown2ExcelConfig 같은 시트 메서드를 .메소드()로 호출하면 에러가 납니다.
- IBS_InitSheet 함수로 시트를 초기화하는데 sheet 객체가 없다는 오류가 납니다. 시트 변수는 var mySheet = ibsheetObject(); 로 만들고 있습니다.
- createIBSheet2로 시트를 만들면 sheetid로 지정한 이름이 아닌 다른 이름으로 객체가 생성되어 가끔 에러가 나거나 시트가 나타나지 않습니다.

**답변**

시트 객체 접근에서 다음을 확인합니다.

- `createIBSheet()`를 통해 전달받는 sheetid는 string 타입이라 시트 객체처럼 `.메소드()`로 호출하면 에러가 납니다. `window[sheetid].메소드()`처럼 window 객체에서 변수명을 찾아 호출하면 해당 시트 객체를 사용할 수 있습니다.
- IBSheet는 `createIBSheet` 함수를 호출하는 순간 `mySheet` 같은 전역 시트 객체를 직접 만들어 주므로 `var mySheet = ibsheetObject();`로 따로 초기화할 필요가 없습니다. 이 선언을 `createIBSheet` 호출 이후에 하면 변수에서 IBSheet 객체가 사라져 오류가 납니다. 선언이 필요하다면 호출 전에 해야 합니다.
- `createIBSheet2`로 만든 시트가 sheetid와 다른 이름으로 생성되는 현상은 명확한 원인을 알기 어렵고 Eclipse 코드 어시스트용 `var sheet = new ibsheetObject();` 구문과 관련이 있을 것으로 추정됩니다. 대응으로 `createIBSheet2()`에서 `IBSheet(...)`가 반환한 객체의 id에 `Table`이 포함되면 이름을 다시 설정하고 `window[sheetid] = res;`로 등록한 뒤 반환하는 로직을 추가합니다.

**키워드**: createIBSheet, createIBSheet2, window[sheetid], ibsheetObject, sheetid, IBS_InitSheet

### [INIT-0006] 시트 높이는 어떻게 지정하나요? createIBSheet 3번째 인자와 높이 값 오타(200x) 문제

**질문**

- IBSheet7 시트의 높이를 지정하거나 다시 조정하려면 어떻게 하나요? SetConfig로 지정하면 되는지 알고 싶습니다.
- DIV 팝업 안에 시트가 2개 있는데 처음 열 때는 둘 다 보이지만 닫았다 다시 열면 첫 번째 시트가 안 보입니다.

**답변**

시트의 높이는 SetConfig와 무관하게 `createIBSheet()` 함수의 3번째 인자를 기준으로 합니다. 예: `createIBsheet('mySheet','800px','100px')`. 화면에 `OnResize` 이벤트나 공통 함수로 높이를 다시 계산해 설정하는 로직이 있다면 그 값이 적용될 수도 있습니다.
높이 값에 `200x`처럼 단위를 잘못 기입하면 팝업을 닫았다 다시 열 때 시트가 보이지 않는 경우가 있으므로 `200px`로 올바르게 지정합니다.

**키워드**: createIBSheet, 높이, OnResize, SetConfig, 시트 안 보임

### [INIT-0007] createIBSheet를 재호출하거나 조건·권한에 따라 생략할 때의 버그와 제약

**질문**

- 이미 초기화되어 화면에 그려진 시트를 이벤트 처리 중에 createIBSheet로 다시 생성해도 되나요? 문제가 생기나요?
- 시트를 생성(createIBSheet)할 때 특정 이벤트나 제공되는 함수를 이용해서 생성 조건을 주고 싶습니다. 가능한가요?
- 권한(role)에 따라 createIBSheet 호출을 막아 일부 시트를 만들지 않았더니 스크립트 오류가 발생합니다.

**답변**

`createIBSheet` 사용 시 다음을 지킵니다.

- 이미 초기화된 시트를 `createIBSheet`로 다시 생성하는 방식은 버그를 유발합니다. 다시 그려야 할 특별한 이유가 없다면 해당 호출을 제거합니다.
- 객체가 생성되기 전에는 특정 이벤트나 함수로 `createIBSheet` 함수를 제어할 수 없습니다.
- 권한에 따라 `createIBSheet`로 시트를 만들지 않으면서 해당 시트의 초기화 함수는 그대로 실행하면 스크립트 오류가 납니다. 시트를 막을 때 초기화 부분도 함께 막거나, 시트별 초기화 부분을 try catch로 묶어야 합니다.

**키워드**: createIBSheet, 재생성, 초기화 함수, try catch, 시트 생성 조건

### [INIT-0008] Reset() 후 createIBSheet 아래에 넣어 둔 기본 시트 설정이 사라지는 이유

**질문**

- Reset()으로 시트를 리셋하고 나니 createIBSheet() 함수 아래에 넣어 두었던 기본 시트 설정이 모두 사라졌습니다. 정상 동작인가요?

**답변**

정상적인 결과입니다. `Reset()`으로 리셋하면 시트 설정이 초기화되므로 기본 시트 설정을 담은 `OnInit()` 메서드를 만들어 두어야 합니다.

**키워드**: Reset, createIBSheet, OnInit, 시트 설정 초기화

### [INIT-0009] table 태그 바로 아래에 createIBSheet 스크립트를 넣으면 IE8에서 오류가 나는 이유

**질문**

- IE8에서만 IBSheet7 오류가 발생하거나, 숨겼다 다시 보여준 시트에 데이터가 나오지 않습니다. createIBSheet 스크립트를 table 태그 바로 아래에 두었는데 원인이 무엇인가요?

**답변**

`<table><script>createIBSheet();</script></table>`처럼 tr, td 없이 table 바로 아래에 스크립트를 넣으면 구조가 맞지 않아 IE8에서 오류가 나는 사례가 있었습니다. table 태그를 지우거나 tr, td도 함께 넣어야 정상적으로 표시됩니다. 숨겼다 다시 보여준 시트에 데이터가 나오지 않는 사례도 같은 구조 문제로 보이는 경우가 있습니다.

**키워드**: createIBSheet, table, tr td, IE8, 시트 구조

## 시트 안 그려짐·크기

### [INIT-0010] 시트가 화면에 그려지지 않을 때 원인 구분과 확인 순서

**질문**

- 운영 사이트에서 IBSheet가 화면에 그려지지 않습니다. 어디부터 확인해야 하나요?
- 교육 때 받은 샘플은 시트가 나오는데 실제 화면에 적용하면 시트가 그려지지 않습니다.
- 가이드대로 코드를 적용했는데 시트가 그려지지 않습니다.
- 조회하면 에러도 콘솔 오류도 없는데 시트가 나타나지 않고 DOM만 생성된 것처럼 보입니다.

**답변**

증상만으로는 원인을 판단할 수 없으므로 아래 순서로 확인합니다.

- 브라우저 콘솔의 에러 메시지를 확인합니다. 원인은 `ibsheet.js` 같은 코어 파일을 import 하지 못한 경우, create 단계에서 오류가 나는 경우, 조회가 되지 않는 경우 등으로 나뉩니다.
- `LoadPage()`가 실제로 호출되는지 확인합니다. 호출되지 않아 시트가 그려지지 않은 사례가 있습니다.
- 사용 중인 제품 버전이 낮아 가이드의 기능을 이용할 수 없으면 시트가 그려지지 않을 수 있습니다. 이때는 최신 버전으로 교체하며, 해당 사례는 IBSheet7 7.0.13.53 버전 배포로 처리되었습니다.
- 에러 없이 시트만 나타나지 않고 헤더를 조건별 함수로 분기해 설정하고 있다면, 분기에 쓰는 함수 이름의 철자와 대소문자 불일치일 수 있습니다. 함수 이름을 짧게 바꿨더니 해결된 사례가 있습니다.

**적용 버전**: 7.0.13.53 배포

**키워드**: LoadPage, ibsheet.js, 시트 안 그려짐, 콘솔 에러, 헤더 분기 함수, 7.0.13.53

### [INIT-0011] 시트 이름(id)이 다른 시트와 중복되면 시트가 그려지지 않습니다

**질문**

- 특정 화면으로 이동했을 때 시트가 그려지지 않는데, 앞서 표시된 다른 그리드와 그리드(시트) 이름이 같은 것이 원인일 수 있나요?
- 한 화면에 시트를 여러 개 생성할 때 시트 id를 모두 같은 값으로 지정해도 되나요?

**답변**

- 달력 관련 표시는 ibmsg의 `Format` 부분을 수정합니다. 메시지는 파일에서 읽거나 변수로 설정할 수 있습니다(도움말 4.2 IBSheet 객체를 생성 부분 참고).

### [INIT-0052] 다국어·영문 메시지를 javascript 변수(Grids.Msg)로 처리하고 헤더도 다국어로 쓰려면?

**질문**

### [INIT-0107] 모든 시트에 공통 컬럼을 추가하려면 IBS_InitSheet에서 어떻게 하나요? (추가 위치 제약)

### [INIT-0123] AutoFitColWidth 속성으로 컬럼 너비를 자동 조정하는 방법과 설정값 종류

**질문**

- 브라우저 창이 최대화 상태가 아닐 때 그리드를 로딩한 뒤 창을 최대화하면 그리드 너비가 저절로 늘어나지 않습니다. 어떻게 해야 하나요?
- 시트를 생성할 때마다 FitColWidth()를 호출하는 것이 번거롭습니다. 컬럼 너비를 자동으로 맞춰 주는 설정이 있나요?
- Cfg의 AutoFitColWidth에 지정할 수 있는 값에는 어떤 것이 있고, 각각 언제 컬럼 너비가 자동 조정되나요?

**답변**

`AutoFitColWidth` 속성을 `ibsheet.cfg`에 설정하거나 시트 초기화 구문의 Cfg(`SetConfig`)에 넣으면, 지정한 시점마다 내부적으로 `FitColWidth()`를 호출해 컬럼 너비를 자동 조정합니다. 시트 초기화, 데이터 조회, 브라우저 사이즈 조절, 컬럼 사이즈 조절 시점마다 시트 객체 너비와 별도로 각 컬럼 너비도 다시 계산됩니다. 값은 `|`로 연결해 지정합니다(예: `search|resize|init`).

- `search`: 조회 및 로드 시점
- `resize`: 시트 Resize 시점
- `init`: 초기화 및 RemoveAll 시점
- `colhidden`: 컬럼 숨김/보임 시점
- `rowtransaction`: 로우 추가/삭제/숨김/보임 이후
- `colresize`: 너비가 변경된 컬럼을 제외한 나머지 컬럼의 FitColWidth
컬럼 너비를 늘렸을 때 가로 스크롤이 생기면 `resize`나 `colresize`가 빠져 있는지 확인하고 누락되었으면 추가합니다.

**키워드**: AutoFitColWidth, FitColWidth, resize, colresize, search|resize|init, ibsheet.cfg, 컬럼 너비 자동 조정

### [INIT-0130] FrozenCol이 적용되지 않거나 틀고정이 기대와 다르게 나올 때, 초기화 에러가 날 때 확인할 점

**질문**

- var cfg = {FrozenCol:3} 형태로 FrozenCol을 설정했는데 시트 아래쪽 스크롤이 생기지 않습니다. 설정이 적용되지 않는 원인이 무엇인가요?

- 시트를 초기화하는 시점에 스크립트 에러가 발생합니다. FrozenCol 설정 값이 원인이 될 수 있나요?
- 컬럼을 고정하려고 FrozenCol 기능을 사용했는데 동작하지 않습니다. 2014년 2월 버전처럼 오래된 IBSheet7 버전에서도 이 기능을 쓸 수 있나요?

아래 항목을 확인합니다.

- `FrozenCol`은 `InitColumns`를 호출하기 전에 설정해야 합니다. 설정 순서가 바뀌면 반영되지 않아 의도한 스크롤이 생기지 않을 수 있습니다.

- 틀고정은 화면에 보이는 제일 끝에 있으면 안 됩니다. 컬럼을 보이거나 숨길 때 틀고정 컬럼을 숨겨서도 안 되며, 틀고정은 반드시 화면의 중간에 보여야 합니다.
- `FrozenCol` 기능은 2014년 2월 버전에는 포함되어 있지 않아 해당 버전에서는 컬럼 고정이 동작하지 않습니다.

**적용 버전**: 2014년 2월 버전에는 미포함

처음부터 헤더 없이 생성하는 것은 지원되지 않습니다. 생성한 뒤 `SetRowHidden(0, 1)`처럼 호출해 헤더를 숨기는 것은 가능합니다.

**키워드**: SetRowHidden, 헤더 숨기기, 헤더 없는 시트

### [INIT-0134] 조회 시 받은 ETC-DATA로 시트 헤더를 동적으로 구성할 수 없는 이유

### [INIT-0135] 탭 화면에서 로딩 중 다른 탭으로 이동했다 돌아오면 헤더 머지가 풀립니다

**질문**

**키워드**: SetMergeSheet, Init_Sheet, SetConfig, 헤더 머지, 탭 전환

### [INIT-0137] 헤더 타이틀을 동적 또는 조건별로 표시하려면 어떻게 하나요? (Header 속성, CellValue)

**질문**

- 컬럼 Header에 데이터 값처럼 동적인 내용을 표시하고 싶은데, Header 속성에 넣은 내용이 문자열 텍스트로만 표시됩니다. 어떻게 하나요?
- 조건에 따라 헤더 텍스트가 달라져야 합니다. 초기화 시점에 조건별로 헤더를 설정하는 방법과 시트 생성 이후에 바꾸는 방법은 각각 어떻게 하나요?

**답변**

헤더 타이틀은 시트 초기화 시 컬럼 정보의 `Header` 속성에 문자열로만 설정할 수 있어, 지정한 텍스트가 그대로 표시되는 것이 정상 동작입니다. 초기화 시점에 조건별로 헤더를 설정하려면 스크립트에서 Header 부분을 변수로 처리하며, `IBS_InitSheet`로 초기화할 때도 마찬가지입니다. `headerText`는 초기화 시에 한 번만 호출되므로, 시트 생성이 끝난 뒤에는 `CellValue()`·`CellText()`로 값을 바꿉니다.

**키워드**: Header, headerText, CellValue, CellText, IBS_InitSheet, 동적 헤더

### [INIT-0138] 헤더 타이틀에 줄바꿈 \n을 넣으면 스크립트 오류가 발생합니다

**질문**

- 헤더 타이틀을 두 줄로 표시하려고 문자열에 `\n`을 넣었더니 스크립트 오류가 발생합니다. 줄바꿈을 넣으려면 어떻게 해야 하며 권장되는 방식은 무엇인가요?

**답변**

컬럼 설정이 문자열로 전달된 뒤 나중에 `eval()`로 처리되는 방식이라 `\n`이 오류가 될 수 있습니다. 현재 방식에서는 `\\n`처럼 역슬래시를 두 번 넣으면 되지만, 컬럼 설정을 문자열이 아니라 오브젝트로 바꿔서 전달하는 것이 좋습니다.

**키워드**: \n, 줄바꿈, eval, 헤더 타이틀, 컬럼 설정 오브젝트

### [INIT-0139] 조건에 따라 컬럼 수·순서·헤더 Text가 달라질 때 시트를 구성하는 방법과 속도 영향

**질문**

- 조건에 따라 시트의 헤더 Text나 컬럼 개수·순서가 달라져야 합니다. 상황별로 어떤 방식으로 시트를 구성해야 하나요?
- 컬럼의 순서나 헤더 텍스트만 조건에 따라 바꾸려면 컬럼 숨김과 위치 이동으로 처리해도 되나요? 컬럼 개수가 많을 때 속도 문제는 없는지 궁금합니다.
- 조건에 따라 표시할 컬럼 수가 다른 시트(예: A 조건은 5개, B 조건은 10개 컬럼)를 만들려면 어떻게 하나요?

**답변**

상황별로 아래 방식을 선택합니다.

- 시트 초기 설정값까지 바꿔야 하면 조회 전에 `DisposeSheet`를 호출하고 시트를 다시 생성합니다.
- 기존 시트를 유지하고 컬럼 순서·헤더 Text만 바꾸면 `MoveColumnPos`(컬럼 위치 이동)와 `ColHidden`(컬럼 숨김)을 쓸 수 있지만, 컬럼 수가 많아지면 속도 저하의 원인이 됩니다.
- 초기 설정은 그대로이고 컬럼만 추가·삭제되면 초기 정보를 만들 때부터 분기해 `Cols`(`cols`) 값을 다르게 세팅합니다. 예를 들어 시트 생성 구분에서 `Cols`를 조건에 따라 분기 처리해 생성합니다.

**키워드**: DisposeSheet, MoveColumnPos, ColHidden, Cols, 조건별 컬럼, 컬럼 순서 변경

### [INIT-0140] 컬럼을 동적으로 구성해 시트를 초기화하려면 Cols 배열에 push로 추가합니다

**질문**

- 컬럼 수나 종류가 조건에 따라 달라서, 반복문이나 조건문으로 컬럼을 동적으로 추가해 시트를 구성하려면 어떻게 해야 하나요?
- DB에서 헤더 텍스트와 컬럼 정보를 가져와 컬럼을 동적으로 구성하고 싶습니다. 이를 지원하는 함수가 있나요?
- 조회 기간 설정에 따라 컬럼 수가 달라지는 시트에서 동적으로 컬럼을 생성하려면 어떻게 해야 하나요?

**답변**

동적으로 컬럼을 생성해 주는 API는 따로 없습니다. 컬럼 초기화 정보는 Json(Object) 구조이므로, 시트를 생성하기 전(페이지 로드 시점)에 컬럼 정보(`Cols`, `cols`)를 동적으로 만들어 생성합니다.

- 컬럼 정의 배열(`Cols`)을 만든 뒤 loop나 조건문 안에서 컬럼 객체를 `push`로 담고, 그 배열로 시트를 초기화합니다(`IBS_InitSheet`). `Object.push()` 같은 자바스크립트 배열 함수로 `cols`에 항목을 추가하면 됩니다.
- 고정 컬럼 배열과 조건에 따른 가변 컬럼 배열은 `concat`으로 합쳐 `Cols`에 지정할 수 있습니다.

**키워드**: Cols, cols, push, concat, IBS_InitSheet, 동적 컬럼, 가변 컬럼

### [INIT-0141] 조회 시점·조회 기간에 따라 컬럼이 달라지는 가변 컬럼 시트(교차표) 구현 방법

**질문**

- 조회 시점에 가변적으로 달라지는 컬럼 정보를 가져와 시트 컬럼 구성을 바꾸고 데이터를 넣어야 합니다. ActiveX에서 하던 이 방식을 IBSheet7에서는 어떻게 구현하나요?
- 조회 기간(시작·종료 월)에 따라 월 컬럼 수가 늘었다 줄었다 하는 교차표 시트를 만들려면 컬럼을 어떻게 구성하고 데이터를 매핑하나요?

**답변**

컬럼 정보에 맞게 시트를 다시 그린(재초기화한) 뒤 `LoadSearchData()`로 데이터를 넣는 방법을 사용합니다. 조회조건의 시작·종료 월로 월 목록을 만들어 컬럼 배열에 동적으로 추가한 뒤 시트를 재초기화합니다. 컬럼 키를 `YYYYMM_개인/법인`처럼 만들면 기간이 바뀌어도 해당 월에만 자동 매핑됩니다. 기간이 길면 컬럼이 많아져 가로 스크롤로 처리되므로 최대 조회 개월 수 제한을 권장합니다.

**키워드**: LoadSearchData, 가변 컬럼, 교차표, 시트 재초기화, 컬럼 키, 조회 기간

### [INIT-0142] 조회 조건에 따라 컬럼 수·타입·헤더 행이 바뀌는 시트를 동적으로 다시 구성하는 방법 (Reset)

**질문**

- 조회 조건에 따라 컬럼 개수·타입·이름이 바뀌어야 해서 시트를 동적으로 다시 구성하는데, 초기화를 다시 해도 처음과 똑같이 나옵니다. 어떻게 해야 하나요?
- 조건에 따라 헤더 행 수나 컬럼 개수가 바뀌거나 헤더 셀병합이 달라져야 합니다. 이미 만든 시트의 헤더 구성을 어떻게 다시 만드나요?
- ajax 응답 후 컬럼을 동적으로 만드는데 조회할 때마다 컬럼이 계속 덧붙습니다. 반복문으로 ColDelete를 쓰지 않고 한 번에 초기화하는 방법이 있나요?
- 시트를 생성한 뒤 특정 시점에 컬럼 구성이 바뀌어 그리드를 다시 그려야 합니다. 그리드를 새로 그리는 함수가 있나요?

**답변**

컬럼의 수나 타입, `saveName`, 헤더 행 개수, 헤더 셀병합 등 시트의 초기 정보가 조건에 따라 바뀌면 `Reset()`으로 이전 정보를 완전히 지운 뒤 다시 구성합니다.

- 조회 버튼을 클릭하는 시점에 `Reset()`을 호출하고, 바꾸려는 컬럼·헤더 정보로 초기화 과정(`InitHeaders`, `InitColumns` 또는 `initSheet()` 등 시트 생성부)을 다시 수행한 뒤 필요하면 데이터를 재조회합니다. 조회마다 컬럼이 덧붙는 문제도 `Reset()` 한 번으로 해결되며 반복문 `ColDelete`가 필요 없습니다.
- 초기화 컬럼을 n개 늘려야 하면 `.push({})`로 원하는 개수만큼 추가합니다.
- 헤더 타이틀 문자열만 바꾸는 경우에는 `Reset()` 없이 `SetCellValue()`(헤더 행은 Rowindex 0부터) 또는 `CellText()`로 간단하게 변경할 수 있습니다. 헤더가 너무 많을 때는 다시 초기화하고 그리는 방식을 쓸 수 있습니다.
자세한 설명은 매뉴얼과 개발자 가이드의 Reset Method 항목에서 확인할 수 있습니다.

**키워드**: Reset, InitHeaders, InitColumns, SetCellValue, CellText, 동적 컬럼, push

### [INIT-0143] 조회 결과에 따라 컬럼이 바뀌는 동적 컬럼 시트의 구현 순서와 빈 컬럼 숨기기

**질문**

- DB 조회 결과나 사용자 조건에 따라 시트의 컬럼 개수와 구성이 달라져야 합니다. 동적 컬럼 시트는 어떤 순서로 만들어야 하나요?
- 조회 조건이나 조회된 데이터 개수에 따라 컬럼을 동적으로 표시하고 싶습니다. 컬럼이 10개인데 데이터는 6개만 있을 때 비어 있는 컬럼을 보이지 않게 하려면 어떻게 하나요?

**답변**

시트의 컬럼은 조회 전에 타입과 개수가 정의되어 있어야 합니다. 따라서 컬럼으로 세팅할 정보를 먼저 조회해 시트를 생성하고, 그 뒤에 데이터를 조회하도록 개발합니다. 시트 생성 시 넘기는 컬럼 정보를 조건에 따라 가변적으로 구성해 전달하면 되고, 조회 이후 컬럼 수가 다시 바뀌어야 하면 `Reset()`으로 시트를 초기화한 뒤 컬럼 정보 조회 → 시트 생성 → 데이터 조회 순서를 반복합니다.
비어 있는 컬럼을 보이지 않게 하려면 `ColHidden` 함수로 컬럼을 동적으로 표시하거나 조회 시 컬럼 정보를 조건별로 생성합니다. 조회해 온 데이터를 기준으로 컬럼을 다시 구성하려면 `Reset` 함수를 호출한 뒤 컬럼 정보를 다시 만들어 시트를 생성합니다.
동적 컬럼 생성 예제는 ibsheet.com 홈페이지 FAQ의 10번 항목에서 볼 수 있습니다.

**키워드**: ColHidden, Reset, 동적 컬럼, 컬럼 숨김, 컬럼 정보 조회

---

### [INIT-0144] colInsert로 동적 컬럼을 구성하면 RenderSheet를 써도 느릴 때 더 빠른 방법

**질문**

- ajax로 받은 컬럼 목록으로 colInsert를 사용해 동적 컬럼을 구성하는데 RenderSheet를 써도 속도가 너무 느립니다. 더 빠르게 구성하는 방법이 있나요?

**답변**

동적 컬럼을 `colInsert`로 구성하면 `RenderSheet`를 사용해도 느린 경우가 있습니다. 이때는 `Reset()` 후에 `CreateIBSheet()`를 다시 호출하는 방식이 가장 빠릅니다.

**키워드**: colInsert, RenderSheet, Reset, CreateIBSheet, 동적 컬럼 속도

## 멀티라인 레코드

### [INIT-0145] 멀티라인 시트에서 Hidden:1을 지정했는데도 컬럼이 계속 보입니다

**질문**

- 멀티라인(다중 행) 시트의 컬럼 초기화에서 Hidden:1을 지정했는데도 컬럼이 계속 보입니다. 정상 동작인가요?

### [INIT-0147] 멀티라인(다중라인) 레코드를 구성하려면 헤더와 컬럼을 어떻게 정의하나요?

**질문**

- 한 건의 데이터를 여러 줄의 행으로 표시하는 멀티라인 레코드를 구성하려면 어떻게 하나요?

**답변**

멀티라인(멀티레코드) 레코드 기능으로 구현할 수 있으며, 한 줄의 row 데이터를 여러 줄의 데이터 행으로 표시하고 주로 컬럼 개수가 많을 때 사용합니다. 매뉴얼에는 관련 설명이 따로 없으므로 ibsheet.com의 멀티라인레코드 예제(DEMO)를 참고합니다. `InitDataProperty()`는 `InitColumns()`로 매핑됩니다.

- `Cols`(컬럼 정보)는 단위 데이터행(DataRow)별 컬럼 배열을 묶은 2차원(다중) 배열로 생성하고, 여러 줄을 차지하는 컬럼에는 `RowSpan`(예: `RowSpan:2`, `RowSpan:3`)을 지정합니다.
- `IBS_InitSheet`로 초기화하거나 `SetConfig`, `InitHeaders`, `InitColumns(initData.Cols,2)`를 각각 호출할 수 있습니다. `InitColumns(cols, 2)`처럼 인자로 dataRow 수를 지정해야 하며, dataRow 안에서 `saveName`이 같은 컬럼은 머지되므로 서로 다른 saveName을 주어야 합니다.
- 다중라인 레코드에서는 Merge 유형에 주의해야 하며 예제는 `MergeSheet:msFixedMerge + msHeaderOnly`와 `PrevColumnMergeMode:0` 설정을 함께 사용합니다.

**키워드**: 멀티라인 레코드, InitColumns, InitDataProperty, RowSpan, MergeSheet, msFixedMerge, SetRowHidden, dataRow

### [INIT-0148] 멀티라인 레코드에서 헤더 줄 수와 데이터 행 줄 수를 다르게 구성할 수 있나요?

**질문**

- 멀티라인으로 데이터 행을 2줄로 구성했는데 헤더는 3줄로 사용해도 되나요?
- 다중라인(멀티라인) 레코드를 쓰면서 헤더 줄 수와 데이터 행 수를 다르게 하려고 RowSpan을 쓰면 스크립트 에러가 납니다.
- ActiveX 화면이 데이터행을 4줄 단위로 구성한 멀티레코드 형태인데 IBSheet7에서는 어떻게 구현하나요?
- RowSpan으로 여러 행을 하나의 행처럼 표시하려는데, 헤더는 한 줄이고 데이터는 여러 줄인 구성을 하나의 데이터 행으로 인식시킬 수 있나요?

**답변**

헤더 영역과 단위 데이터 행의 줄 수는 동일하게 맞추는 것이 원칙입니다. 줄 수가 다르면 화면에는 보일 수 있어도 내부 로직에서 오동작이 발생할 확률이 높고, 다중라인 레코드에서 헤더 줄 수와 데이터 행 수가 맞지 않으면 스크립트 에러가 발생합니다. 헤더 한 줄에 데이터 두 줄을 하나의 데이터 행으로 인식하는 구성은 지원하지 않으며, 여러 행을 하나처럼 표시하려면 갤러리 예제처럼 데이터 행과 헤더행의 개수가 같아야 합니다.

- 헤더를 3줄로 표시하려면 헤더 배열을 3개 두고, 데이터에는 `RowSpan`을 사용해 2줄로 표시되도록 구성합니다.
- 기존 화면이 헤더행 4줄, 데이터행 5줄이었다면 양쪽을 5줄씩 생성한 뒤 `SetRowHidden()`으로 불필요한 행을 화면에서 숨깁니다.
- `SetConfig`, `InitHeaders`(3줄), `InitColumns`(2줄)로 시트를 생성하면 가능하다는 답변도 있고, 헤더와 데이터 영역의 행 수가 같을 필요는 없을 것으로 보인다는 의견도 있으나 확정되지 않았습니다. 기존 화면이 그렇게 구성되어 있다면 업무적 특성을 먼저 확인합니다.

**키워드**: RowSpan, SetRowHidden, InitHeaders, InitColumns, 멀티라인 레코드, 헤더 줄 수, 데이터 행 줄 수

### [INIT-0155] 이미 초기화된 시트를 다시 초기화(재생성)하려면 Reset()을 먼저 호출해야 하는 이유

**질문**

- 이미 생성한 시트를 다시 생성(재초기화)하는 함수가 있나요? 시트를 다시 만들려면 어떤 함수를 어떤 순서로 호출해야 하나요?
- 검색 조건에 따라 같은 화면에서 시트를 다시 초기화하는데 이전 컬럼이 남거나 컬럼 수가 변경되지 않고 데이터 바인딩도 어긋납니다.
- 조회 조건에 따라 시트 구조가 바뀌도록 SetConfig부터 InitColumns까지 다시 호출했는데 화면에 변화가 없습니다.
- 시트를 이미 초기화한 상태에서 조회할 때마다 초기화 함수를 다시 호출했더니 시트를 클릭해도 클릭 이벤트가 발생하지 않습니다.

**답변**

이미 초기화(init)된 시트를 다시 초기화하려면 먼저 `Reset()`을 호출해 초기 정보를 지운 뒤 초기화 함수(`IBS_InitSheet`, `SetConfig`, `InitColumns` 등)를 다시 호출합니다. 시트를 다시 그릴 때도 `Reset()` 호출 이후에 시트를 생성하는 구문을 다시 호출해야 합니다. 이후 `LoadSearchData` 등으로 데이터를 넣습니다.
`Reset()` 없이 초기화 구문만 다시 실행하면 다음 증상이 생깁니다.

- 화면에 변화가 없거나 컬럼 수가 바뀌지 않고, 이전 컬럼이 남으며 데이터 바인딩이 어긋납니다(컬럼을 줄일 때도 늘릴 때도 마찬가지).
- 헤더 병합이 깨지거나 시트가 정상적으로 그려지지 않고, 시트를 클릭해도 클릭 이벤트가 발생하지 않을 수 있습니다.
`SetConfig`는 시트 초기화 시 한 번만 호출되는 함수이고 `IBS_InitSheet` 안의 내용도 최초 1회만 호출할 수 있습니다. 속성을 다시 적용하려면 `Reset()` 후 `SetConfig`, `initHeader()`, `initColumns()`를 다시 호출합니다.
초기화 함수 안에서는 시트 객체가 이미 있는지(`window["mySheet"] != undefined`) 판단해, 없으면 `createIBSheet2`로 생성한 뒤 초기화하고 있으면 함수 시작 부분에서 `Reset()`을 먼저 호출합니다. 데이터만 바꾸면 되는 경우에는 시트를 다시 만들지 말고 데이터만 변경합니다.

**키워드**: Reset, IBS_InitSheet, SetConfig, InitColumns, createIBSheet2, LoadSearchData, 재초기화

### [INIT-0156] 시트 재초기화 시 사용자가 이동한 컬럼 순서나 conInsert 이후 컬럼 구성을 유지·복원하는 방법

### [INIT-0157] Reset() 후 시트가 다시 만들어지지 않거나 조회가 안 될 때: 반환값을 시트 변수에 다시 대입
